## 环境边界

授权服务器为 Debian GNU/Linux 12 (bookworm)、x86_64、Linux 6.1，LAN 接口 ens32，约 4 GiB 内存。存在 Docker 网桥和运行中的服务，初始没有 /etc/netgo 或 /opt/netgo。不会把已有服务状态、身份或网络配置作为可清理的临时文件。

参考项目：<https://github.com/sck03/sing-box-vpn>，本轮阅读其 README 和 install.sh，参考独立入口、菜单、校验及本机卸载行为；不复制源码。NetGo 的技术范围仍按原方案执行。

本轮结果逐项追加。源码完成、自动验证、真实安装、业务网络验收和正式发行保持独立状态。不得记录 SSH 密码、PAT、管理员密码、私钥或完整含密钥配置。

## 范围追加与当前过程

用户明确要求所有可用环境的功能都实测，并授权当前 Windows 设备参与。实际客户端为 Windows 10 企业版 LTSC 1809、x64；不将其结果写作 Windows 11。Windows 桌面进程当前未提升权限，服务安装需要系统正常的管理员提升流程。

已经完成两端基线读取、七个缺失 Debian 包安装（0 升级、0 卸载）、SHA-256 固定 Go 1.27.4/Node 26.13.1 的准备；前端在 Linux 构建与七项行为测试通过。第一轮 Go 下载遇到网络超时，停止该次等待后改用实际可达的 Go 模块镜像，不关闭依赖摘要验证。上述均为过程记录，不等于最终集成通过。

隔离内核测试：`unshare --net env NETGO_PRIVILEGED_TESTS=1 gateway-kernel.test -test.run TestKernelLeaseRenewalAndRevocation -test.v`。测试主动拒绝主机网络命名空间；先复现归属误报，再复现 20 秒租约续至 110 秒后内核仍只有 18 秒、撤销后元素仍存在；修复后通过，其他表保持存在。原始日志将在最终整理时脱敏归档。

Windows 用户随后实际执行管理员安装，安装记录 PASS，NetGoNetBird 为 Running/Auto；当前普通用户进程可使用其受限管道。新版窗口、四个分页和普通编辑表单已启动，Ctrl+L、Ctrl+N 实际触发。当前 Windows 10 LTSC 的截图接口返回 `0x80004002`，点击返回 `coordinate input geometry is unavailable`；已明确保留鼠标和视觉验收限制。未保存的表单测试进程结束后重新启动，不把工具未能点击取消视为已通过。

真实 API：`live-api.json` 的 28 项检查全部 PASS，包括受信 TLS、私有入口拒绝、协议要求、签名、防重放、真实 Dex 登录/刷新、普通账号权限、资源授权、设备限额、禁用/过期、最后管理员保护和脱敏。该结果来自 Debian 12 的完整原生服务，不使用身份模拟服务。
