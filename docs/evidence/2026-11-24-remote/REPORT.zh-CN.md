# 远控时钟、传输与 Windows 交互完善

日期：2026-11-24，Asia/Shanghai。沿用单NetGo.exe、API v2 / schema2和现有VPN身份、授权与原生媒体接口。

## 修改

- 服务端库存返回 next_generation，包含当前设备的已关闭会话；客户端不再用本机时间戳生成代次。重启与其他设备隔离、上限检查有回归覆盖。
- 授权响应返回 server_unix_ms；控制端和 Windows 主机以可信控制响应加完整请求耗时计时。包含休眠的系统单调时钟用于期限，续租以新的认证响应校准时间；已过期的单调期限仍终止会话，不从媒体对端或票据自行校时，不放宽30秒租约。
- TLS分片接收保留状态，单个消息总期限3秒，轮询返回不暴露半条消息；媒体循环不再因不完整头/正文等待3秒。帧仍限4MiB，控制限64KiB。
- TCP_NODELAY、POSIX poll、高描述符处理和SIGPIPE抑制；不改进程全局信号处理器，断开连接返回错误。
- Windows默认视频保持桌面比例，最高1280×720、20fps、目标3Mbps，不放大小屏；先成功采集/初始化编解码再确认媒体格式。窗口保持画面比例，黑边和工具栏滚轮不发送输入。
- 新增“停止”，取消媒体/输入、清除画面和待发事件；结束服务端会话使用独立清理期限。仅观看不截获本地快捷键，普通鼠标释放不再释放仍按着的键盘修饰键。

没有新增第三方媒体依赖、用户账号体系、公共STUN/TURN或数据库格式。新增控制响应字段要求服务端与客户端一起更新；旧开发服务端不作为本轮客户端的运行依据。

## 本地与 Debian 验证

Windows 11项CTest、TLS夹具、系统DLL与10MiB预算检查已执行。共享客户端真实TLS/持钥证明、观看权限、±24小时服务端时钟偏差、取消和服务端会话清理有回归覆盖。真实DXGI桌面完成1280×720的30帧编码→解码，未保存屏幕图像；其耗时只代表这段本地编解码检查，不能当作网络帧率。

Debian13使用系统OpenSSL3.5.9，在独立验证目录执行6项共享核心/票据/传输/客户端ASan/UBSan检查。首次验证漏打包共享票据向量导致一项失败，补齐测试输入后全部通过；原始失败日志保留。新用例包含分片、慢速滴传、已关闭对端及高描述符连接。没有更改实机已有LAN/VPS服务、默认网关、SSH或Docker。

Go internal/cmd 全部测试与vet已执行。续租新增了模拟服务端时间前移12秒、经过真实TLS连接的回归，验证两帧之间成功续租与校准；原始测试夹具未切换active状态导致的失败已保留并修正。对应日志摘要、最终云端运行和提交记录见CI.json。开发日志、输入包与构建缓存仍在忽略目录，不进入用户运行包。

Windows使用computer-use检查本轮远控测试窗口：按钮结构和空闲停止禁用状态确认，Alt+F4退出后窗口与进程均结束。当前Windows10 LTSC的截图接口返回0x80004002，鼠标输入几何不可用；不将无障碍结构检查算作视觉或真实鼠标输入验收。测试未启用真实站点远控或修改用户网络。
