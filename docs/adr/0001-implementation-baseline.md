# ADR-0001：实施基线与证据边界

日期：2026-11-21。状态：身份、网络和证据边界仍接受；Wails 桌面路线已于 2026-11-22 被 ADR-0002 的原生 C++ 路线替代。

执行 R01–R12 的单站点 Linux 服务和 Windows 客户端范围；以 NetBird 完整协议链、独立本地 Relay/STUN、可选 frp 通道为基础。所有普通用户必须有真实身份，不能共享 setup key。

按用户最新要求选择最新稳定开源依赖。Wails 从方案候选 v2 升至官方稳定 v3；记录接口适配及构建结果。Go 采用官方稳定工具链，依赖以锁文件固定。

P0 的真实网络门槛不能在 Windows 编译环境完成。先交付可审阅源码、协议和安全测试、部署与验收工具；发布门槛维持关闭，直到 G1–G6 与 A01–A33 有实际证据。这是实施顺序的调整，不改变网络验收要求。
