# ADR-0003：受管配置与发行事务

日期：2026-11-22（Asia/Shanghai）。状态：接受；适用于 0.2.1-dev。

Linux 使用 Go 实现配置、发行校验和故障恢复，systemd 执行固定服务操作；Windows 使用 PowerShell 安装原生 C++ 产品与独立 NetBird 服务。禁止从远端请求执行任意 shell。

配置事务只修改现有站点的运行参数，保留 issuer、数据库和秘密来源。每次写入前建立独占恢复目录；失败恢复原文件和服务，再协调原策略。辅助入口/TLS/Relay 配置必须作为独立部署包渲染并验证。发行事务只接受 protocol 2/schema 2/Linux amd64 产品包；校验可信清单摘要、文件摘要和版本格式，停写后生成加密快照，健康失败切回旧目录。上游组件或不可逆数据库升级不由该命令自动处理。

网关以 table comment 标记归属。与受管接口冲突的 flow offload 会绕过常规 hook，因此发现时拒绝启动。会话撤销或同地址重授权采用先关闭受影响 IP、定向删除 conntrack、再放行的顺序；失败保留关闭状态并重试，绝不 flush 全机连接。

Windows 安装使用受保护恢复目录，保存旧文件和原服务运行状态，校验可执行路径与桌面 SID。安装失败恢复旧程序；强制中断保留日志供人工恢复。配置、凭据和系统网络规则的真实恢复仍须通过 A21–A29，模拟测试不能替代该验收。
