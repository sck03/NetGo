# ADR-0004：版本化入口、协议检查与 Debian 基准

日期：2026-11-22。状态：源码实现；真实部署验收待执行。版本：0.2.2-dev。

## 决定

用户的服务端基准改为 Debian 13 amd64，Windows 仍为 C++20，Linux 产品/CLI 仍为 Go。本地公网默认高位端口，H3C 多 WAN 和可选 VPS 的职责不变。系统包按 Debian 提供，Go/Node/Caddy/frp 使用项目版本锁；Linux 实际 GCC、glibc、内核、HAProxy 与证书客户端版本由验收环境记录。

产品 API v1 保留现有请求格式，健康响应发布能力，受保护 API 要求明确协议头。不兼容时在认证/写入之前拒绝。所有客户端须与对应服务端和上游桥接程序成套更新，旧开发包不进行静默兼容降级。

站点 ConfigRevision 使用可被 JSON/JavaScript 精确表示的非负整数；0 仅用于旧开发文件。客户端在认证后取得新配置，固定站点 ID、Origin、CA，拒绝版本倒退和同版本内容冲突。先验证新候选可达，再原子保存。活跃会话不热替换 profile；下一次连接使用新候选，既有候选仍按 DNS/网络变化恢复。

配置回滚重新发布旧内容时使用更高版本。配置事务预留一个恢复版本，避免部分客户端已取得新版本后无法接受恢复配置。

账号 AuthRevision 属于产品元数据，不含密码材料。账号修改同时删除产品凭据并递增代次，使在途认证无法越过撤销边界。密码维护通过原 NetBird IdP 管理命令从 stdin 输入，NetGo 不读写 IdP 密码数据库。失败保持维护状态，恢复记录无密码；既有 OIDC JWT 仍遵循标准有效期，LAN 的立即关闭由产品凭据/租约负责。

## 运维与可观测性

Caddy/frp 纳入 Linux 组件构建与所有权清单。TLS/443 使用 netgo-caddy/netgo-haproxy 单元，证书 hook 指向受管 TLS 服务。安装预检查只读，不自动改包源、放端口或启用 VPN。

服务端每 30 秒采样受管服务、可信控制健康、Relay TCP、证书和磁盘。管理 API 输出脱敏检查、告警和进程计数；JSON 请求日志不含请求体、参数、用户或令牌，只用随机 trace_id 关联。外部网络和真实 LAN 状态只能由对应 Axx 实验证明。

## 证据

共用配置契约在 Go/C++ 执行；另覆盖认证撤销、密码维护故障、配置同步失败、回退版本、协议拒绝、日志脱敏、证书告警和 Debian 预检查。历史命令、版本及限制见 [历史验证索引](../HISTORY.zh-CN.md)，当前验证见 [当前重构记录](../REFACTOR_CURRENT.zh-CN.md)。
