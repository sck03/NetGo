## 修复与模块边界

- **Apple 控制响应**：`ControlResponse` 统一识别独立的 `{"error":"code"}` 操作失败。状态对象的空或非空诊断 error 正常交付给 UI，修复 iOS 把健康 VPN 判为断开的错误。Linux/macOS HTTP 状态及 Windows 独立错误对象语义保持一致；新增正常、恢复中、取消、空错误回归。
- **本地服务恢复**：Unix IPC 在用户私有目录持有永久锁文件，验证 owner、文件类型、链接数量和目录权限。仅在持锁、确认 socket 属于本用户且连接被拒绝时回收残留；不覆盖普通文件或活动监听。listener 关闭先释放 socket 再释放锁。Linux `ServiceSupervisor` 与 macOS `DesktopService` 独立管理存活和最多 32 秒退避，恢复进程不自动重放结果不明的写请求。macOS 的连接装配移入 `DesktopRuntime`，App 入口仅负责场景。
- **音频故障降级**：Android `RemoteAudio` 与视频解码独立；设备不可用时提示并保持画面。复用 19,200 字节 PCM 暂存区，减少逐包拼接和切片；短时积压丢弃待播 PCM，不增长队列。Apple 复用音频格式，播放引擎失败提示静音，队列上限时跳过 PCM。畸形媒体、取消或授权失效仍结束会话。
- **Android 视频和展示**：`RemoteVideo` 使用独立 Codec 回调线程，静止桌面的最后一帧无需等待下一网络包。压缩包最多排队两帧，输入压力等待有上限；不静默丢弃压缩参考帧。`NativeRemote` 保留 JNI 和会话职责。协商宽高传至 Compose，画面按原比例居中并限制高度，触控区域就是实际画面区域。
- **管理页错误状态**：概览、会话/设备、远控授权分别保留读取与操作错误。读取成功只清除读取错误；轮询不能清掉失败操作。操作已成功但随后读取失败，不向调用者报告写入失败或自动重放。会话与设备仍独立分页；保留草稿、编辑冲突和查询取消规则。
- **查询和取消**：schema 9 增加 `remote_grants(host_id,id)` 索引。历史分页分别构建首屏和游标查询，加入可被表达式索引利用的时间范围，同时保留时间/ID 二元游标。Go SQLite 查询计划回归验证两条路径使用 SEARCH。VPN 续租保持已有单身份读取，SQL 全部使用请求 context，回退网关查询亦支持取消；撤权与网关提交栅栏、持久 nonce 保留。
- **远控命令工作线程**：主机文件/剪贴板线程按首个命令启动。取消代次传至执行中的授权回调，排队的旧代命令返回取消错误，保留八个命令和一个取消槽；Windows 取消同步 I/O，析构重复取消并 join。平台所有者仍等执行者完成后释放资源，不使用悬空线程。
- **清除失效假设**：移除 Android 旧同步解码排空及逐包音频拼接、界面内直接持有进程和重复错误恢复逻辑。维护实验脚本从已安装程序/清单获取版本与协议，不再写死 schema 1、0.2.4 或 amd64。清理脚本加入本轮工具/编译目录。
