# 当前重构与验证记录

更新：2026-11-28（Asia/Shanghai）。本轮基线 `f2f1e60`，当前为 **0.3.0-dev / API v2 / SQLite schema 8**。沿用现有 Vue 卡片、表单、分页与原生界面，不维护旧开发接口、数据库迁移或双写。

## 修复与架构调整

- **原生凭据恢复屏障**：Go 的 `client/control.go` 与 Windows controller 在刷新响应不确定时禁止业务请求发送旧 token；共享远控将 `authentication_refresh_pending` 作为暂时错误。锁等待与两次请求共用 4 秒预算，单次请求最多 2 秒。只有成功恢复才更新凭据并解除屏障；取消、真实撤权和原有 6 秒 watchdog 仍生效，不延长权限或自动重放业务写入。沿用服务端两分钟加密恢复机制。
- **账号创建异常面板**：定时刷新复用未完成查询，避免每十秒取消一个可能需要二十秒的请求。翻页、操作和卸载使旧查询失效；成功读取只清除读取错误，保留操作失败提示。服务端生成 `can_manage`，列表和人工操作共用十分钟等待规则，前端不依赖本地时钟。
- **前后端契约统一**：管理列表、摘要、审计、网络设置和异常任务由实际 Go DTO 生成 TypeScript。审计列表展示操作者 ID，历史账号删除后仍可追溯，不为名称额外加载全量账号。
- **请求取消贯通**：管理摘要、分页、账号选项、审计、远控历史及远控依赖读取使用请求 context。查询中断可释放连接等待与 SQL 工作；权限核验、原子撤权和必要补偿仍保留。
- **定向远控写事务**：主机注册只读取该主机的活动会话；授权编辑/删除只读取该授权及活动会话，再补齐双方账号、设备、凭据、VPN 租约和主机依赖。已存在授权使用活动主机索引，不加载所有用户、设备、授权或关闭历史。旧 `RemotePolicyUpdate` 全表入口及失效辅助代码已删除，提交栅栏、回滚、策略版本和审计保留。
- **网络策略版本**：使用明确的网络字段比较，名称、编辑 token/版本及清理重试元数据不再触发 NetBird 策略重算；资源集合、CIDR、协议、端口、启用状态、账号有效期和远控路由变化仍推进版本。编辑并发和认证撤权版本保持独立。
- **原生清单精简**：`GET /netgo/v2/remote` 仅返回 `hosts / next_after / next_generation`；删除未被客户端消费的 grants/sessions。管理接口仍提供所需授权和会话；页内忙碌状态和可用能力继续在服务端按完整依赖计算。
- **远控工作线程**：文件/剪贴板线程按首个命令启动，空闲时等待事件，在途请求按协议截止时间唤醒，取消原先每 10ms 的空闲定时唤醒。保留八个在途请求、取消预留、迟到回复退休、完成事件释放平台文件和 reset/join 所有权。
- **Windows 视频路径**：解码回调借用锁定 NV12 平面及实际行距，直接写入复用的 BGRA 展示缓冲，移除一次整帧中转复制。像素转换独立为 `video_pixels.cpp`，每个 2×2 块复用色度计算；颜色整数舍入、边界检查及最多三个展示缓冲不变。
- **模块职责**：API 路由装配、签名认证、HTTP 响应、管理查询 DTO 与管理写入拆分；Go 客户端签名传输与凭据屏障从 Controller 中独立。没有为了减少行数压缩状态处理，或引入未使用的兼容层。

## 保留的实现边界

- VPN 全局网关规则仍在事务提交栅栏内生成/应用；没有为了缩短事务而引入撤权竞态。
- Windows 查看端仍为 CPU 颜色转换与 GDI 展示；本轮优化复制和色度计算，没有实现 GPU 解码/呈现。GPU 全链路、移动真机、跨设备音视频、弱网、休眠、多屏、UAC 和长期 CPU/RSS/时延仍需平台验收。

- `legacyOwnedTable` 是仍在使用的 nftables 环境适配，保留；schema 1–7 仍在修改前拒绝，没有新增迁移。
