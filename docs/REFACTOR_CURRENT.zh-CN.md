# 当前重构与验证记录

更新：2026-11-27（Asia/Shanghai）。基线 `cc36472058c310b7812089df60abdcc5d513e625`。当前为 **0.3.0-dev / API v2 / SQLite schema 5**。本轮修复已经确认的业务缺陷和平台适配问题，保留现有 Vue 管理界面及各平台原生交互，不引入旧接口、旧数据库迁移或双写。

## 账号与授权一致性

- 账号创建在上游 POST 前持久化用户名、邮箱及创建意图；两个唯一索引阻止同一数据库中的并发重复创建。先检查上游已有身份，不接管已有账号。上游调用不持有数据库或会话锁。
- 对明确未取得连接、明确拒绝的请求释放预留；响应丢失、截断或缺少 ID 时保留记录。后台按邮箱和名称核对结果，清理未完成的上游账号；已在本地提交的用户受到保护。进程重启后继续恢复，不保存初始密码，不自动重复 POST。
- 活动创建有恢复宽限期和请求截止时间；最终入库再次检查截止时间及管理员凭据。未能确认结果时保留预留，不以一次空查询判定操作不存在。若身份服务持续不可用或账号信息被外部修改，需要管理员核对上游及恢复日志；不要绕过 NetGo 并发创建相同邮箱。
- 管理概览展示待核对／清理任务数，创建错误有明确说明。身份服务只返回一次的初始密码丢失时，完成清理后重新创建，不能伪造或恢复原密码。
- 至少保留一个启用、未删除且不过期的管理员；禁止把最后一个永久管理员设置为未来到期、停用、降级或删除。界面说明与后端规则一致。
- 显示名称更新不再改变认证版本或撤销租约；角色、停用、到期、限额和资源权限改变仍原子撤权。资源选择先去重排序，顺序变化不触发无意义撤销。
- 远控授权账号选择器只返回启用且未到期的用户，已有授权继续显示原账号。失效账号在后端返回独立错误码，前端显示原因。

## 远控记录与存储

- schema 5 的活动远控会话通过条件生成列继续受用户、主机和控制设备外键约束；已关闭记录脱离活动对象生命周期。删除设备／账号时同一事务关闭活动会话、撤销路由，保留 24 小时历史。
- 关闭时清除控制凭据引用，公开历史继续脱敏；已删除账号／主机的标签回退为 ID，分页游标不依赖被删除对象。
- 签发票据使用 `RemoteAcquireUpdate`：仅加载申请用户及目标主机涉及的活动会话、当前幂等键和完整授权依赖。generation 最大值及全局容量在同一 SQL 写事务内检查，不再把全部历史和闲置身份反序列化、复制到 Go。
- 移除已经没有生产调用者的全量 `RemoteUpdate` 入口；主机／授权修改、单会话续期、历史清理和新会话签发有各自的存储入口。网关应用仍保留提交保护边界，nonce 防重放仍使用持久原子消费，不为减少写入而降低一致性。
- Dex 的 OIDC verifier/JWKS 缓存按 provider 实例复用，保留库内密钥轮换；缓存生命周期不绑定第一次登录请求。

## 原生客户端与资源使用

- Windows/Linux 共用 C++ 控制错误响应编码，Apple 主机和查看端共用 Swift 适配；macOS IPC 保留 HTTP 状态和 JSON 错误。Android 将 Go 错误转换为 JSON 返回共享核心，避免 JNI 清除异常后把拒绝授权误当成网络故障。
- 共享重试策略只接受明确的传输失败、截止时间及本地队列忙；授权失效、权限不足、冲突等仍立即停止，现有 watchdog 限制不变。
- Android 远控组合以站点、主机和每次尝试为身份。切换目标或点击同一主机重连都会创建新视图和 Surface；旧回调留在旧组合内，文件选择器的临时 Surface 保留机制继续使用。原生启动失败也释放媒体及 Surface。
- Android 工作线程在整个会话期间保持 JNI 附着，缓存视频／音频方法 ID；媒体字节数组仍使用明确的逐包所有权，不复用正在被解码器消费的内存。
- Apple H.264 解析直接借用 Data 的字节，不再先复制整个 `[UInt8]`，普通 NAL 直接写入预分配帧缓冲；参数集保留必要独立副本。保留原有帧顺序与有界回压。
- Linux 查看端新增可选音频播放模块，复用已有 GStreamer 依赖，协商 AUDIO 后才创建播放管线。48 kHz 双声道 S16LE 的 appsrc 排队上限为 19,200 字节，写入异常或持续积压终止会话，防止无限占用内存。Linux/macOS 被控端仍不声明系统音频采集。
- Linux IPC 控制适配与音频播放从窗口入口拆为独立模块；账号创建恢复和远控签发也从大服务文件拆出。保持依赖方向：界面／平台适配 → 共享协议与会话 → 领域服务 → 存储；不引入新的服务定位器或全局兼容层。

## 必要验证

本轮只执行与变更有关的验证，不进行全仓库、全平台或实机全套验收。

- Go 定向包：accounts、store、model、remote、session、identity、api、operations、contracts、engine/netbird；覆盖创建结果丢失后重启恢复、已有上游身份保护、管理员未来到期、仅名称修改、失效账号过滤、四种身份删除下的历史保留及原子撤权。
- 定向 race：以上新增关键用例、并发及跨连接 nonce 消费。
- 前端：管理认证、账号分页、页面状态和新错误提示回归；`vue-tsc --noEmit` 与 Vite 生产构建。
- C++：独立编译并执行共享控制错误／重试回归，Linux 控制桥接以 `-Wall -Wextra -Wpedantic -Werror` 检查语法。
- 相关 Go 包 `go vet`、契约重新生成与 Linux amd64 全部 cmd 入口交叉编译通过；文档本地引用、Git 空白检查及数据库打包版本保持一致。

本机实际使用 Go 1.27.3、Node 24.18.0 和 GCC 16.1；正式构建仍遵循锁定工具链，未降低工程版本要求。本机没有 Linux GTK/GStreamer 开发环境、Android SDK 或 Apple SDK，因此未声称 Linux 音频、Android 生命周期、Apple 媒体及完整 Windows 应用已完成本轮平台编译或设备验收。没有测量可对外承诺的整体 CPU、内存、延迟或吞吐提升比例。
