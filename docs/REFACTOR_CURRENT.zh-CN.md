- 账号增加独立 `edit_revision`。保存必须匹配当前版本，过期编辑返回 HTTP 409 / `edit_conflict`；存储提交也为依赖清理、密码与设备管理造成的账号变更推进编辑版本。旧页面不能覆盖刚停用的账号或恢复已移除的权限。
- 编辑版本与 `auth_revision` 分离。显示名称修改保留凭据和 VPN 租约；角色、停用、到期、限额与权限变化继续原子撤权。无变化保存不推进版本。最后一个永久管理员保护、创建意图持久化和失败恢复继续保留。
- 管理界面保留用户草稿，发现账号版本变化后禁用保存，提供“载入最新设置”；服务端冲突后刷新列表。TypeScript DTO 由 Go 模型生成，错误对象保留错误码与 HTTP 状态。
- 上游账号检查、远控 peer 查询、Dex 授权／令牌端点和 JWKS 获取故障返回 HTTP 503 / `control_unavailable`。明确停用、无权限、peer 不存在或离线仍终止授权；故障不会签发凭据或延长票据。共享 C++ 仅在现有 watchdog 窗口内重试此可恢复错误，6000 ms 截止不变。
- 保存相同资源、修改资源名称或仅调整端口顺序／重复项，保留现有 VPN 会话；地址、协议、有效端口或启用状态变化及删除仍撤销相关连接。端口保存前排序去重。重复保存相同远控授权保留 revision 和会话，实际授权变化继续关闭旧会话。

## 存储与资源占用

- 文件数据库使用 WAL、一个写连接和最多四个只读连接，读事务不再排队等待网关写事务。每条连接配置 busy timeout、外键与同步策略，只读池额外启用 query_only；内存测试数据库仍使用单连接。
- 身份读取、持久 nonce 消费、VPN 事务及续期接受 context，连接池等待可以取消。网关 Apply、撤权、nonce 原子消费及失败关闭仍在原有提交边界内，未移出事务。
- 账号／设备／资源／VPN 变更共用活动依赖图，不再反序列化保留的远控历史和无关远控幂等键。关闭记录独立于身份生命周期，仍保留 24 小时。
- schema 6 增加凭据、VPN 租约、操作键、远控操作键和关闭历史的过期索引，以及管理员设备索引。远控活动检查与历史过期查询分开；每次最多回收 256 条过期历史和 256 条远控操作键。活动会话仍全部校验，未因批次上限推迟撤权。
- Linux BGRA 显示使用三个有界共享缓冲；GTK 纹理继续持有不可变像素，引用释放后才复用。缓冲忙时完成 H.264 解码后跳过显示，保持参考帧链。最多保留三份分辨率上限内的像素缓冲，不无限排队。
- 发布程序流式复制至独占创建的暂存文件，保留权限、Sync 和复制后校验；不再一次读取整个可执行文件。备份 AES-GCM 直接写入预分配输出，去掉中间密文副本，现有认证加密格式与 256 MiB 备份上限不变。

## 平台控制适配与模块边界

- Linux 查看端／主机 IPC 观察远控活动状态；普通远控控制请求最多 4 秒，结束 DELETE 使用独立 2 秒截止，关闭远控无需断开 VPN。Linux/macOS IPC 响应上限与 Go／共享 C++ 对齐为 4 MiB，超限返回独立终止错误。
- Go mobile 的 `RemoteCall` 接收 `RemoteActivity`，每 50 ms 检查当前查看器的取消状态；Android 由该查看器实现活动接口。无活动对象的清单读取保留有界截止，清理 DELETE 独立于查看器停止。
- Apple 远控路径使用带活动回调的 `RemoteRequest`；macOS 的独立 `DesktopIPC` 模块向 curl 传递取消回调。iOS 使用 UUID 标记 provider 请求，取消消息绕过普通请求队列；队列内和正在执行的 Go 调用都能观察取消。提前到达的取消标记有数量与时间上限。
- 新的职责模块为 `model/control.go`、`model/user_revision.go`、`model/resource.go`、`identity/verification.go`、`mobile/remote.go`、Linux `frame_pool.hpp` 和 macOS `DesktopIPC.swift`。平台界面只提供活动状态与展示，授权策略留在领域服务，共享协议与存储边界不变。
- 删除重复的 session 提交包装和旧 mobile 不可取消调用路径。没有发现需要删除的整块无调用后台功能；后台恢复、主机心跳和 nonce 入口有实际调用方。nftables 输出兼容逻辑不属于旧产品 API，继续保留。
