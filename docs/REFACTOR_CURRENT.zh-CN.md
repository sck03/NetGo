# 当前重构与验证记录

更新：2026-11-28（Asia/Shanghai）。审计基线 `51fe6bb0752adf26e30fb603e7082f65b7ffb0da`。当前为 **0.3.0-dev / API v2 / SQLite schema 7**。沿用现有 Vue 卡片、表单和原生界面；不提供旧开发接口兼容、数据库迁移或双写。

## 权限编辑与契约

- Resource 和 RemoteGrant 增加随机 `edit_token`：创建用空 token，更新必须匹配当前 token。事务内发现对象已变更、删除或重建，返回 HTTP 409 / `edit_conflict`。随机 token 防止删除重建后旧页面再次匹配。
- 资源和授权表单刷新后保留草稿，冲突时禁用保存并提供“载入最新设置”。账号原有 `edit_revision` 和独立 `auth_revision` 继续保留。
- 规范化后的无变化保存保留 token、授权 revision 和活动会话。资源名称变更保留租约；有效访问范围变化继续撤权。
- 账号页只返回当前页账号已选资源的名称；资源选择器支持名称/IP 搜索、每页最多 50 项，翻页和搜索保留已选项。DTO 继续由 Go 生成 TypeScript。
- 诊断统一由 `/admin/summary` 的 `runtime` 返回；诊断导出和网络验收脚本已同步。删除重复 `/admin/diagnostics`，不保留兼容路由。

## 存储与取消

- 账号创建只加载相关用户名/邮箱候选及当前管理员凭据、设备，提交前再次检查管理员和唯一性。创建预留、失败补偿和结果未知恢复不变。
- 删除失败只更新目标重试记录，设备最终删除只加载活动依赖图，避免读取全部远控历史。重试记录使用独立 2 秒事务截止，调用方取消后仍保留退避时间。
- 远控注册、心跳、授权、清单、签发、续期、消费、结束操作把请求 context 传到事务，连接池等待可取消。后台远控/租约清理各有独立 4 秒截止，创建失败补偿独立限时 2 秒。
- schema 7 增加邮箱查询索引；保留 WAL、单写/有界读连接、持久 nonce 和分批历史清理。打包器从 Go 模型读取 protocol/schema，去掉重复版本常量。

## 平台修复与模块化

- iOS TunnelRequestQueue 增加加锁的 `isClosed`，修复 provider 编译错误；构建脚本先运行提前取消、正在执行/排队时关闭、重复关闭及关闭后提交回归。
- Unix TLS 监听设置 `SO_REUSEADDR`，允许 TIME_WAIT 状态下重新绑定，不启用端口共享。回归覆盖真实 TLS 交换后的连续重启及第二个活动监听拒绝。Windows 保持独占绑定。
- host 测试记录启动错误和返回码，避免把启动失败误报为 consent policy。原失败原因的最终确认以本轮 Linux CI 为准。
- Linux 提取输入映射、剪贴板、同意弹窗，通过回调注入窗口/主线程调度/活动状态；Windows 提取文件选择和高级配置弹窗。
- `gateway.Render` 包装移入测试文件；保留实际使用的移动 API、协议验证及受支持系统所需的 nftables 差异处理。
- 七个平台工作流覆盖共享 scripts 和安装脚本，补齐 macOS 客户端服务源码路径。Windows 安装登记版本读取校验后的维护程序 ProductVersion，保留预发布/构建后缀。
