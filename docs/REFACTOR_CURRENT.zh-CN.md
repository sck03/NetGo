# 当前重构与验证记录

更新：2026-11-28（Asia/Shanghai）。本轮基线 `a722b72`。当前为 **0.3.0-dev / API v2 / SQLite schema 8**。沿用 Vue 卡片、表单、分页与原生界面；不维护旧开发接口、旧数据库迁移或双写。

## 已完成的修复与边界

- **刷新结果丢失恢复**：凭据轮换时，同事务保存使用原 token 与 refresh token 派生密钥加密的结果，恢复窗口两分钟且不超过新凭据期限。必须使用原设备签名和新 nonce，携带同一 refresh token。旧 token 仅能进入刷新恢复端点，不能访问业务 API；撤权、删除、过期和后续轮换会使恢复失效。恢复记录随数据库重启保留；事务 Clone 深拷贝恢复指针和密文。上游尚未返回、或上游已经轮换但本地尚未提交时的进程崩溃，仍不能凭空恢复上游丢失的响应。
- **nonce 容量与热路径**：schema 8 使用插入/删除触发器维护计数，避免每次 COUNT；过期清理最多每秒一次。达到 65536 条时返回 `503 control_capacity_exceeded` 和 `Retry-After: 1`，不再将容量不足误报为凭据失效。原子消费、持久化重放保护和事务串行化保留。
- **账号创建异常可处理**：待处理项记录创建时间、最近核对时间和状态；提供独立分页查询、重新核对和人工释放接口，账号页展示对应操作。结果未知时继续后台核对，不能因暂时查询不到账号而自动放弃预约。人工处理待确认项须等待十分钟；释放前管理员明确确认原上游请求已经结束，服务端再次查询邮箱不存在，并在提交时核验管理员身份和任务版本，记录审计。
- **远控管理数据有界**：主机清单只读当前页主机和活动会话依赖；授权按选中主机独立分页，每页最多 50 条。选中账号单独查询当前授权及编辑 token，避免跨页将已有授权误判为新建。`RemoteGrants.vue` 管理授权草稿、分页和冲突；`RemotePanel.vue` 管理主机和活动会话，原生 `/remote` 清单契约不变。
- **前端取消与一致性**：LatestQuery 失效会中止实际 fetch，切页、改搜索或卸载不会继续消耗旧查询资源；认证刷新仍是共享屏障，单页取消不清除登录。统一编辑冲突提示，不再把资源/授权都称为账号。Go DTO 重新生成 TypeScript，前端重新构建。
- **远控输入容错**：共享主机输入回调区分成功、不支持事件和平台故障；不支持事件释放所有已按输入并放弃本批剩余事件，保留画面和命令连接。Linux/macOS 补充大小写锁定、数字键盘及功能键映射；Linux 保留左右修饰键和 extended 标记。X11 文字按当前布局预检并处理 Shift，不可映射文字明确拒绝。macOS 滚轮按轴累积不足一格的输入，释放时重置，不再逐次截断。macOS 仍只映射平台支持的 F1–F20；不承诺任意 X11 Unicode 布局都可注入。
- **上游查询与发行维护**：锁定的 NetBird 用户 API 只有全量列表和当前用户接口，不假定存在任意用户 GET。改为逐项解码，设备发现只保留目标账号候选 ID，跳过并发消失的 peer，再验证密钥和归属；不缓存授权状态。Linux 发行校验与构建端采用相同 SemVer 和 16 位数字限制，支持 `1.2.3-rc.4+ci.9`。
- **代码清理**：删除未使用的 `Store.Read`、源码安装兼容入口、重复卸载包装及旁路版本切换脚本。安装统一根目录安装器，维护/升级/回滚统一 Go 路径；验证脚本同步删除失效入口。保留当前生产调用、平台差异适配、锁文件和必要回归夹具。
