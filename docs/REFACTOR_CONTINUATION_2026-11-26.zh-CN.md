# 2026-11-26 接续审查修复与优化

基线：`f7ea69de554c61e58c228caae850c8e92e473efb`。当前采用 **0.3.0-dev / API v2 / SQLite schema 3**。不提供 schema 1/2 自动迁移、旧接口回退或双写；打开旧数据库会先拒绝，再由管理员在新目录初始化。本轮没有修改已安装站点的数据库。

## 修复结果

| 问题 | 当前行为 |
| --- | --- |
| 纯远控账号被 LAN 网关连接状态阻塞 | Go 与 Windows 对空资源租约不再等待网关路径；本地状态新增 remote_ready，五个平台按远控工作者、身份和租约状态启用远控，保留各自主机授权与门禁。 |
| 上游核验占用会话全局锁 | Acquire/Renew 在锁外核验上游；进入提交阶段重查凭据、设备、租约和代次，撤权可在核验等待时完成。网关执行与数据库提交仍在同一保护范围。 |
| 退出后密码残留、远控页认证过期但仍显示登录 | AdminSession 统一通知认证变化，父页面清空业务数据和查询；初始密码使用独立一次性状态，退出、失效、页面切换或后续操作均清空。 |
| 远控历史按随机 ID 排序、续期覆盖开始时间 | created_at 与 issued_at 分离，ClosedAt 首次关闭后保持；按创建时间和 ID 倒序分页，游标独立于上一页记录是否保留。关闭后最多保留 24 小时；账号/设备删除仍按领域归属移除记录。 |
| 一个失败设备阻塞后续清理，账号删除状态不明确 | 设备/账号先提交本地撤权，失败返回 202 与 cleanup_pending。持久化 1–32 分钟退避，每项超时 2 秒，失败继续处理其他项；独立后台循环每分钟扫描，单类预算 8 秒。待删除账号不可重新启用。 |
| Android 同名下载失败、下载退出后累积 | 独立 RemoteDownloads 管理每次会话和下载的唯一缓存路径；导出失败可重试或丢弃，传输及导出持有文件直至完成，页面退出后清理。导出期间禁用重复导出和丢弃。 |
| Linux 操作控件未同步协商权限 | 独立 RemoteActions 绑定剪贴板、上传、下载和取消控件；按协商能力启用，断开或结束时复位。 |
| Apple 临时呈现繁忙直接中断，导入文件先完整读取 | 视频保留当前参考帧，最多 10 次、每次 5 ms 等待呈现可用；超时/授权失效仍停止。站点导入移到后台分块读取，最多读取 64 KiB + 1 字节，超过上限拒绝。 |
| 原生主机测试续期返回旧票据 | 夹具校验并递增序号、更新签发/到期时间及签名；加入 60 ms 检查延迟，并要求完成两个续期周期后结束，消除依赖传输先于续期完成的时序。 |

## 存储、性能与模块边界

- 存储事务共用读取、提交、依赖清理、审计与策略版本逻辑；remote_target.go 只加载目标会话及其完整授权依赖。心跳、检查、消费、续期、撤销均使用明确的目标事务。
- VPN 续期只加载活动远控；策略核对不加载已关闭会话，定时远控清理只加载活动/已到期记录和过期幂等项。创建会话仍检查保留历史的代次与总量，保持防重放与容量约束。
- 无策略变化的 NFT 续期以单批次刷新 active4/internet4 超时集合，保留规则和计数；真实授权变化仍完整更新并清理对应 conntrack，每分钟执行完整规则修复。没有把网关操作移出撤权保护范围。
- 概览/诊断使用 admin/summary，账号、资源、设备按页面查询，每页 50 项；用户编辑同时加载资源选项，设备页加载租约及对应账号标签，远控授权页单独加载账号选择项。诊断补齐 goroutine、请求/错误、CPU 累计时间、峰值 RSS 和磁盘空间。
- 清理调度、摘要分页、远控定向事务、下载生命周期、Linux 权限控件和 Windows 状态文案均独立成模块。移除无消费者的 /netgo-ui/mode、Selector.Dial 和 RemoteRead；CI 路径过滤补齐工具/契约测试及 Web 测试。
- schema 3 明确包含新清理状态、远控时间字段和历史索引；打包及运维校验同步。报告格式和 VPS 配置包各自的 schema 标识是独立格式，不随数据库版本修改。

200 个账号/设备的内存数据库短基准（同一次运行，100 ms 采样）：

两种查询返回的数据不同；此数据只说明概览读取减少了解码和分配，不代表磁盘、网络、完整应用或部署后的性能提升比例。基准运行期间有其他构建任务，未做长时压测。
