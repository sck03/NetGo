# VPN 与远程桌面的统一集成契约

日期：2026-11-27。当前实现以本契约和 [远控功能说明](REMOTE_HOST_FEATURES.zh-CN.md) 为准。Windows/macOS/Linux 被控主机和各平台控制端已接入；观看、输入、音频、剪贴板、上传、下载按主机实际能力独立协商。本机可选择无人值守，系统权限和站点授权仍须满足。真实设备组合验收尚未全部完成。

## 1. 统一体验，保留独立生命周期

一个站点、一次账号登录、一个设备列表、一个原生客户端。用户选择获准设备后发起远控；主机是否在线、网络是否可达、是否允许观看、是否允许输入分别显示。没有输入权时只能观看，未开启主机功能的设备不出现“可控制”状态。安装器可选择主机组件；使用 VPN 不会自动开启被控能力。

三套状态机通过明确事件协作，不合并成一个连接布尔值：

| 状态机 | 负责 | 不授予的权利 |
| --- | --- | --- |
| 站点会话 | 账号、控制端设备、站点信任、登录/退出和凭据期限 | 不因登录就可以访问所有设备 |
| 网络通道 | 已批准 peer、地址/端口、直连/打洞/中继和路径变化 | 通道连通不等于允许采集屏幕或操作键鼠 |
| 远控会话 | 指定双方设备及主机启动实例、同意、能力交集、租约、撤销 | 网络重连不自动恢复已撤销的远控或提升权限 |

UI 只消费快照、发出类型明确的命令。UI 线程不得等待网络、采集、编解码或文件 IO；取消必须到达执行者。Windows 用户入口为同一个 NetGo.exe，后台与远控由其内部模式自动启动。进程隔离与代码模块边界保留；用户不需要分别启动多个 EXE。不同平台替换 UI/安全存储/VPN/媒体适配，共享身份、会话和协议规则。

## 2. 模块与数据方向

| 模块 | 输入与输出 | 依赖边界 |
| --- | --- | --- |
| 控制服务 `internal/remote` | 主机登记、授权、签名短期票据、续租、撤销及审计 | 引用现有唯一 IdP/网络管理；不持有媒体帧 |
| 连接协调器 `internal/client` / Windows controller | 站点会话 + 目标设备 → 已批准网络通道；发布路径/断线事件 | 不将 NetBird 内部 Go 对象暴露给原生 UI |
| `packages/remote-core` | 已验证票据 + 双时钟 → 会话/能力/终止原因 | 纯 C ABI，不依赖窗口、GPU、媒体 SDK、套接字或后台线程 |
| Windows 用户会话主机执行器 | 门禁快照 → 采集/输入/音频工作者 | 每个敏感操作检查能力；停止后释放帧、音频、按键与文件临时状态 |
| `apps/windows/remote` | 指定显示器 → 同步借用 GPU BGRA surface，按需合成独立光标 | DXGI/D3D11 与窄 GDI 光标适配；GPU/COM 句柄不越过平台层进入共享 ABI |
| 编码/传输/解码/渲染 | 有界帧或数据包 → 对端播放 | 独立适配；编码器不能创建第二套账号/配对/公网协调服务 |

Windows 主机身份与特权协调属于受限服务；采集/音频/普通输入属于交互用户会话代理。锁屏/UAC/用户切换单独设计、单独验收，不通过给 UI 管理员权限解决。Linux、Apple 的系统权限也不能由共享核心绕过。

## 3. 连接、恢复与终止的顺序

1. 客户端验证站点版本、证书和时间，再认证；协商双方真正实现的能力。
2. 服务端在同一事务检查账号、设备、主机授权、VPN 租约和并发上限，签发绑定双方及主机启动实例的短期授权。需要本地同意时等待主机用户操作。
3. 网络适配器只为批准的双方建立最小地址/端口策略。主机验证服务端签名及控制端持钥证明，并原子消费一次性票据。
4. 主机门禁通过后才启动被允许的工作者。观看不包含输入；当前音频和输入逐项取交集。剪贴板、上传、下载独立授权并逐命令检查，使用有界共享传输模块。能力不足返回稳定错误，不静默换成外部播放器或放宽授权。
5. 直连/中继变化只改变传输路径。短暂断线期间停止输入并释放按键；恢复需要重新验证通道绑定和当前租约。过期/撤销后使用新会话，禁止复活旧 generation。
6. 退出站点、切换站点、账号/设备/授权被禁用、主机重启、租约过期或用户拒绝时，先关闭敏感操作门禁，再取消采集/编码/传输及待发队列；释放按键，终止文件传输，回收网络授权，最后报告完成。

退出的本地执行必须立即开始；远端在线撤销目标为 5 秒内，通信中断时由最长 30 秒主机租约兜底，轮询不超过 100 ms。不能承诺断网两端“瞬时同步”，也不能仅靠客户端退出按钮或网关 nftables 撤销主机权限。双时钟回拨、挂起恢复、通知丢失均属于验收。

续期按最近的服务端授权序号推进，快照可领先或落后于对端 offer，不要求逐张精确相遇；每次仍验证签名、绑定、同一代次、递增序号、权限不扩大和有效期。输入单次文字最多 8192 UTF-8 字节，最多 128 事件 / 60 KiB 一批；平台通过共享核心取得上限，明确处理拒绝入队。移动端文字草稿显式发送，退格/回车以完整按键对提交。队列接受只表示入队，失焦、断线与陈旧输入不得重放。

## 4. 媒体复用的决策门槛

MiniRTC 保持候选，不能因为跨平台就默认打包其全部 SDK。必须先证明能够使用 NetGo 的身份、已批准传输路径、取消和租约，不额外运行上游账号/配对/信令服务器。不能禁用重复能力、跨层依赖过重或无法满足包体/许可要求时，替换为窄媒体适配，不推翻领域和 C ABI。

Windows 已接入 DXGI → D3D11 NV12 → Media Foundation 硬件编码，失败时明确软件回退。macOS 使用 ScreenCaptureKit → VideoToolbox，Linux 使用 X11 或 portal/PipeWire → GStreamer。Android/Apple 平台层管理 Surface/设备资源，共享层管理会话与包格式。

Windows/macOS 硬件路径使用平台纹理；Windows 的独立光标通过复用的 GDI 兼容纹理合成，驱动同步成本需实测。Windows 软件回退和 Linux 管线可能经过 CPU，Windows 查看端仍有 CPU 颜色转换。原始帧允许丢弃，已编码参考帧不得静默丢弃；Windows GPU 样本最多 8 个，异步编码器释放样本后才可复用。文件最多 8 个分块在途并逐项确认，共用 TLS 通道；主机文件/剪贴板任务有独立的单工作线程和最多 8 个未完成任务，取消与析构回收有明确所有权。独立网络 QoS、自适应码率和高时延性能仍需后续优化和实测。

Windows 路由 RPC 只传去重的 CIDR，对象名称、协议和端口留在服务端授权及界面模型中。Windows 与 NetBird RPC 请求都限制为 2 MiB；网关完整策略上限继续为 1 MiB / 1024 租约。新旧开发版本不混用。服务端单租约续期只能更新已安装且资源策略未变的成员；未知、过期或需要修复时在同一 SQL 写事务内回到完整策略路径，不放宽撤权或提交失败关闭要求。

Windows 引擎适配使用可取消异步管道，锁等待及完整读写共用 25 秒预算。普通手动配置必须从 revision 0 引导；正式配置到达后保持单调版本和信任身份约束。Agent 恢复只重试读取或退出，不能重放结果未知的连接变更。远控进程与窗口必须匹配请求站点。

查看端 `AsyncExchange` 独立拥有文件 IO 和协议状态，最多 8 个在途命令、有界请求/响应/完成事件；平台回调仍由 run 调用线程交付。10 秒命令超时退休请求 ID，取消该传输并忽略迟到回复；协议错序或认证失败仍结束会话。取消必须在文件发布前复核，释放所有者前 join。Windows 查看端最多三个 BGRA 帧缓冲，保持不可变展示引用；软件和 GPU 对显示模式变化使用相同的初始协商画布，宽高比变化不偷偷改变协议尺寸。

VPN 活动事务及主机/授权变更可跳过已关闭历史，必须保留当前路由全部依赖和 revision 失效；账号/设备删除使用完整所有权事务。签发需要历史 generation 和幂等检查，不能用活动集合替代。

主机在 8 个普通命令之外预留 1 个取消请求位置，避免满队列使超时取消被拒绝。取消确认也超时后暂停新命令，待迟到的清理确认到达才恢复；媒体和授权检查继续运行。

| 编号 | 可重复场景 | 必须观察的结果 |
| --- | --- | --- |
| I01 | 有 VPN 权、无远控权；有观看权、无输入权 | 能访问获准 LAN；拒绝启动远控或注入输入；不分配无权工作者 |
| I02 | 同一站点 Windows↔Windows、Android→Windows | 原生内嵌画面/输入/音频；双方身份、票据、会话与路径记录对应 |
| I03 | 观看中降权、撤销账号/设备/授权、站点退出 | 门禁先关、队列丢弃、按键释放；记录主机最后敏感操作时间，不只查 UI |
| I04 | 强制直连→中继→直连；丢包/限速/换网 | 不重复配对、不扩大权限；队列/内存有界；记录中断与恢复时延 |

| I08 | 文件/剪贴板与高帧率会话同时运行并随时取消 | 内存/队列/并发上限有效；取消不死锁；不残留越权文件或剪贴板内容 |
| I09 | 客户端启动/退出、连续重连、72 小时 | 线程/句柄/内存无持续增长；帧耗时、CPU、RSS、包体有实测基线 |
| I10 | 空库安装 v2、旧版客户端、卸载重装 | 新库/接口一次切换；旧版明确拒绝；停止旧栈后按归属清理，无双写 |

## 6. 当前接口与后续验收

- 概览和诊断轮询 `GET /netgo/v2/admin/summary`，只返回 counts、策略版本/错误与运行指标。列表使用 `GET /netgo/v2/admin/state?section=users|resources|sessions|devices&after=<cursor>`，每页 50 项、响应 next_after。sessions 按有效租约分页并附对应设备/账号标签，devices 单独分页；两者游标互不影响，过期或已停用账号的租约不显示为有效会话。用户编辑加载完整资源选项；远控管理页使用独立主机分页和可搜索账号选择接口，`section=remote` 已移除。缺少 section 的旧全量接口不再支持；未使用的 `/netgo/v2/me` 已删除，认证探测使用 `/netgo/v2/site`。
- Go/Windows 客户端站点名为 1–256 UTF-8 字节，GatewayIP 必须是 IPv4，非空 CA 必须可解析且不超过 32 KiB。服务器初始化允许尚未分配网关 IP，但禁止向客户端导出未完成配置。保存的密码绑定协议、ID、HTTPS 主机名（忽略大小写）和 CA，候选地址/端口/显示名不属于信任锚点。
- 账号创建在上游请求前写入 schema 6 的 account_cleanups 预留，按用户名／邮箱唯一约束；请求失败按已知未提交或结果未知分别处理，未知结果禁止直接重试 POST。恢复时先核对上游和本地所有权。至少保留一个启用且不过期的管理员；仅修改显示名称不撤销认证和租约。概览 counts.account_cleanups 显示未完成项数。
- 管理状态不再包含 audit；通过 GET /netgo/v2/admin/audit?before=<sequence> 分页，每次最多 100 条，next_before 为 0 表示没有更早记录。
- 主机接受 windows/macos/linux、显式本地无人值守策略及实际实现的六项能力。登记必须提供每次启动生成的 transport_key；重启关闭旧会话。保留不可连接主机的状态和有效能力；客户端只允许 ready 状态发起连接。
- /netgo/v2/remote/key 已移除，授权响应包含 site_key；所有内置客户端同步使用这一响应。
- 未指定会话限额统一默认为 1；容量错误为 gateway_capacity_exceeded，不会撤销其他有效租约。
- 自动化回归覆盖竞态、容量、权限清理、审计分页、会话代次和媒体队列；真实画面、键鼠、音频、换网与长期稳定性按 I01–I09 分平台验收。

## 7. 本轮接口与生命周期约束（2026-11-26）

- `health.server_unix` 必填，Go、Windows、Web 使用相同范围校验；仅支持当前 API v2/schema 6。活动远控使用条件外键保证所有权，关闭记录独立保留 24 小时；删除身份同事务关闭会话并撤销访问。签发读取相关活动图，并在同一事务中校验 generation、容量和幂等键。
- 设备删除先提交本地撤权：移除凭据、VPN 租约、被控登记、相关授权及远控会话。上游删除失败返回 HTTP 202 `{deleted:false,cleanup_pending:true}`，设备显示 `delete_pending:true`，禁止重新签发该设备凭据。后台清理独立于租约过期检查，每分钟扫描到期待重试项；单项超时 2 秒，失败按 1–32 分钟退避并继续处理其他项。账号删除采用相同的 202、delete_pending 和持久化重试语义，待删除账号禁止恢复权限；上游 404 视为成功。管理页区分已完成与待清理，支持手动重试。
- 认证事务只在实际注册的匿名路由限流：直接来源最多 90 请求/分钟、全局最多 900；本机 TLS 代理共享全局预算，不信任任意转发头。签名验证通过后的刷新按设备独立限制 12 次/分钟；账号失败尝试仍独立限制 5 次/分钟，成功登录不占失败预算。
- `GET /netgo/v2/remote` 只返回当前活动会话；`next_generation` 仍计入保留的历史会话。`GET /netgo/v2/admin/remote/history?before=<cursor>&limit=50` 返回 `{sessions,next_before,users,hosts}`，上限 100，管理员专用。created_at 为毫秒精度、不可变的创建时间；issued_at 是当前票据签发时间；closed_at 记录首次关闭，关闭后保留 24 小时。按 created_at 与 ID 组合倒序分页；next_before 为不透明游标，客户端原样回传，即使上页末行已清理仍能继续分页。每页通过同一 SQL 查询附带对应账号/主机标签，不依赖当前主机列表页；已删除对象回退显示 ID。控制凭据字段不对外返回。
- 已认证账号可建立没有 LAN 资源的 overlay 租约。空资源集合不会产生 LAN/互联网授权，桌面访问仍须独立远控授权与主机门禁。互联网出口继续单独检查。Go/Windows 本地状态新增 remote_ready，表示当前身份、租约和远控工作者就绪；所有平台远控入口、主机列表和停止逻辑使用该字段，与 LAN 网关路径独立。
- 主机允许 NetBird 管理 ACL 生效，保持默认拒绝；网络策略只授予获准控制端到主机指定 TCP 端口。未受管的启用策略仍阻止 NetGo 应用策略。不得用全局放行代替授权。
- 客户端清理超时保留旧 worker 的完成信号；旧 worker 结束前不能启动新连接。Android 文档选择器只暂停画面呈现并释放输入，普通退后台、退出或销毁仍停止远控。
- 后台策略核对独立于本地过期清理：本地版本变化及时处理，至少每分钟检查上游漂移，失败按 5–60 秒退避。数据库持久化层不拥有领域依赖清理规则，规则统一在 `model.PruneDependencies`。
- Windows 每个站点候选分别复用探测、普通/VPN、远控三条 TLS 连接，30 秒空闲后重建；等待连接锁计入请求截止时间，慢 VPN 请求不会占用远控连接；证书与规范 Origin 校验保持，失败连接丢弃，不自动重放写请求。引擎 RPC 使用一个受父进程 Job 管理的子进程逐行交换有界 JSON；断开、超时或取消销毁该子进程。
- 查看器等主机消费会话后保留服务端序号，每 3 秒直接续租；续租重新校验当前权限并返回递增序号，不再在每次续租前重复 GET。主机授权读取由控制监视线程完成，媒体线程只应用与会话 ID/票据匹配的短期快照；旧票据过期或监视失联仍立即关闭。文件传输最多 8 个分块在途，保持顺序、偏移、取消和完整性验证。

## 8. 分页、账号与平台生命周期

- `GET /netgo/v2/admin/remote/inventory?after=&q=` 仅管理员可用。每页 50 台主机，按 ID 升序，返回 `hosts/grants/sessions/users/next_after`；授权和活动会话仅属于本页主机，仍校验当前凭据及完整会话依赖。`q` 搜索全部主机名称/系统，页面状态筛选只作用于本页；计数明确标注“本页”。
- `GET /netgo/v2/admin/users/choices?after=&q=` 返回 `{users:[{id,alias,name}],next_after}`，每页 50 项，排除待删除账号；按用户名和显示名称搜索。两个接口的 `after` 原样回传，`q` 最多 128 个 Unicode 字符，不返回账号权限详情。空游标从第一页开始，空 `next_after` 表示结束。
- 登录名 `alias` 创建后不可改，违规更新返回 `alias_immutable`，不能先修改凭据再报错。`name` 是 NetGo 管理页显示名称，修剪空白，空值使用登录名，最多 256 UTF-8 字节。创建账号时也向上游传递名称，后续显示名编辑以本地字段为准；不新增另一套上游账号资料编辑 API。
- Go 客户端连接流程与路由选择分别由 `connection.go`、`routes.go` 管理。初始连接、续租和恢复的每次路由操作最多 15 秒；认证刷新后的引擎重新登录、启动、路由共用 20 秒恢复期限。更短的父期限或取消优先。
- iOS 的独立 `TunnelRuntime` 从系统偏好恢复现有管理器并观察状态；停止在偏好读取完成前也有效，异步连接使用代次校验，应用启动不隐式发起新登录。Android 只在界面可见或连接进行中查询状态，终止状态移除 VPN 前台通知；返回界面重新建立服务入口。上述改动仍需设备验证。
- Android/Apple 提供“仅查看”和音频请求选项，传给共享查看器能力协商；不会启用主机未登记的能力。Linux X11 按轴累计细粒度滚动增量，释放输入时清空余量。
- 认证注册/刷新与远控扫描使用独立、定向的存储入口，保留原有写锁、事务、配额与撤权检查。领域规则留在 `identity` / `remote`，数据库模块只选择所需记录并持久化变更。

## 9. 审查修正（2026-11-27）

- 服务关闭进入不可逆的会话停止状态；在途授权提交也必须检查。停止状态返回 HTTP 503 `session_manager_stopped`。清理失败可以重试 Close，Reset 不得恢复授权。
- 资源 `ports`、账号和租约的 `resources` 即使输入为空、null 或未提供，也统一输出数组 `[]`。共享 DTO 类型从 Go JSON 模型生成，执行 `go generate ./internal/contracts` 更新；`go test ./internal/contracts` 检查漂移。测试共用 `tests/contracts/resource-icmp.json` 验证后端响应和 Vue 组件。
- Go 凭据刷新含可取消锁等待共 4 秒；Windows 锁等待和刷新 HTTP 分别最多 4 秒。普通请求与轮换的顺序约束不变；父请求取消优先，不自动重放写请求。
- iOS 应用消息最多 2 个同时执行、8 个未完成；隧道停止直接取消连接且拒绝新消息，排队消息仍获得结束响应。生命周期与网络执行器独立。
- 文件交换目录的 `.netgo-exchange.lock` 为零字节锁标识，不能按普通临时文件删除。同目录上传和崩溃回收互斥；只回收可识别的过期 `.part`，其他普通隐藏文件也占配额。持锁进程退出后由 OS 释放锁。
- Linux 与其他端的“仅查看”选择只收窄键鼠输入；其他能力仍由独立授权控制。GTK 呈现保持不可变帧引用直到纹理释放。
- 管理页显示清理失败次数及 `cleanup_after`；`cleanup_attempts` 饱和于 6，显示为“6 次及以上”。实现、测试与尚未完成的设备验证见 [审查交付记录](https://github.com/sck03/NetGo/blob/cc36472058c310b7812089df60abdcc5d513e625/docs/REFACTOR_REVIEW_2026-11-27.zh-CN.md)。

## 2026-11-27 一致性补充

- `GET /netgo/v2/remote?after=<cursor>` 返回最多 50 个 host、`next_after` 和 `next_generation`。空 cursor 读第一页，空 `next_after` 表示结束。各页基于独立 SQL 快照，不是跨页冻结快照；客户端要求 cursor 严格前进，最多 200 页。列表刷新与创建会话仍分别鉴权，不把列表当作授权缓存。
- 原生接口仅返回当前账号对应主机的 grants 和当前设备参与的 sessions。管理员的全站授权管理使用独立的 `/admin/remote/inventory`。忙碌状态仍加载页内主机的活动会话及完整依赖后判定。
- Windows IPC 请求保持 1 MiB，响应与 HTTP/共享远控均为 4 MiB；超限明确返回 `ipc_response_too_large`，不再静默丢弃响应。分页正常返回远小于此上限。
- 管理页普通请求可以并发，刷新凭据必须排空已开始的普通请求；刷新开始后新请求等待同一轮换结果。登出取消旧代请求，失败操作不自动重放。
- `netgo-rpc routes` 接受空资源并显式清空网络选择；重复 CIDR 去重。空 LAN 授权不等于没有 overlay/远控权限。
- daemon Login metadata 新增 `netgo-gateway-ip`、`netgo-local-relay`，来自受信站点 Profile；`netgo-candidate-kind` 必须与候选一一对应，删除“省略类别时按位置推断”的旧分支。移动绑定同步传入同样配置。
- 客户端到网关沿用客户端可达中继；普通客户端之间优先双方可共享的非本地中继，否则按互补 controller 顺序选择。识别网关使用 Management 提供的 peer overlay IP 与站点 GatewayIP 比较，不能由 peer offer 自称网关；选中 URL 仍要求在 Management 发布列表中。
- 远控遇到暂时控制面故障可在剩余 watchdog 时间内重试，失败不会刷新 watchdog；续租响应丢失后先读取当前 sequence。明确撤权、非法响应、取消和到期都终止，不恢复已关闭 generation。
- Go DTO 是资源、账号、设备、租约、远控主机/授权/分页与运行诊断的类型来源；执行 `go generate ./internal/contracts` 更新 TypeScript，不手工修改生成文件。

## 2026-11-28 编辑、故障和取消契约

- `User.edit_revision` 为必需输出字段，账号 PUT 原样回传读取时的版本。服务端在事务内比较，冲突返回 HTTP 409 `edit_conflict`。它独立于 `auth_revision`；元数据变化推进编辑版本但不撤销认证，无变化保存不推进。界面刷新最新账号后要求用户重新载入并核对草稿，禁止自动重放过期权限写入。
- 上游暂时不可用返回 HTTP 503 `control_unavailable`；取消返回 HTTP 408 `control_cancelled`。明确账号失效仍为 unauthorized/forbidden；已移除 peer 为 not_found，真实离线或绑定错误仍为 remote_host_unavailable。C++ 只在未到期的现有 watchdog 窗口内重试 control_unavailable，错误不刷新租约或票据。
- 资源 ports 规范化为有序去重数组。相同资源或仅 name 变化不撤销已有租约；CIDR、protocol、有效 ports、enabled 变化或删除仍撤权。相同 RemoteGrant 的 capabilities/expires_at 不变时保留 revision 和活动会话。
- Linux/macOS IPC 响应限制为 4 MiB，与 Go HTTP／共享 C++ 一致；请求上限不扩大。超限为 control_response_too_large。远控请求通常最多 4 秒；Linux/mobile 的结束 DELETE 为独立 2 秒，macOS/iOS 最多 4 秒。敏感操作仍由既有票据和 watchdog 的更短期限约束。
- mobile.RemoteCall 新签名追加 RemoteActivity；Android 查看器实现 controlActive，清单调用可传空。Apple 的 RemoteRequest 传递会话活动回调。iOS provider 普通消息必须携带 UUID id；取消为 `{cancel:id}`，直接更新活动状态，不排队等待慢请求。取消标记最多 64 个、有效 30 秒，不影响其他请求或 VPN。
- schema 6 的文件库使用单写连接、最多四个 query_only 读连接；所有连接启用外键及 busy timeout。关键事务使用 context，网关提交保护和 nonce 原子消费不变。关闭历史／远控操作键每轮各清理最多 256 条，活动会话校验不受此上限影响。
