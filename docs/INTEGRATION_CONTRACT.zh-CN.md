# VPN 与远程桌面的统一集成契约

日期：2026-11-26。当前实现以本契约和 [远控功能说明](REMOTE_HOST_FEATURES.zh-CN.md) 为准。Windows/macOS/Linux 被控主机和各平台控制端已接入；观看、输入、音频、剪贴板、上传、下载按主机实际能力独立协商。本机可选择无人值守，系统权限和站点授权仍须满足。真实设备组合验收尚未全部完成。

## 1. 统一体验，保留独立生命周期

一个站点、一次账号登录、一个设备列表、一个原生客户端。用户选择获准设备后发起远控；主机是否在线、网络是否可达、是否允许观看、是否允许输入分别显示。没有输入权时只能观看，未开启主机功能的设备不出现“可控制”状态。安装器可选择主机组件；使用 VPN 不会自动开启被控能力。

三套状态机通过明确事件协作，不合并成一个连接布尔值：

| 状态机 | 负责 | 不授予的权利 |
| --- | --- | --- |
| 站点会话 | 账号、控制端设备、站点信任、登录/退出和凭据期限 | 不因登录就可以访问所有设备 |
| 网络通道 | 已批准 peer、地址/端口、直连/打洞/中继和路径变化 | 通道连通不等于允许采集屏幕或操作键鼠 |
| 远控会话 | 指定双方设备及主机启动实例、同意、能力交集、租约、撤销 | 网络重连不自动恢复已撤销的远控或提升权限 |

UI 只消费快照、发出类型明确的命令。UI 线程不得等待网络、采集、编解码或文件 IO；取消必须到达执行者。Windows 用户入口为同一个 NetGo.exe，后台与远控由其内部模式自动启动。进程隔离与代码模块边界保留；用户不需要分别启动多个 EXE。不同平台替换 UI/安全存储/VPN/媒体适配，共享身份、会话和协议规则。

## 2. 模块与数据方向

| 模块 | 输入与输出 | 依赖边界 |
| --- | --- | --- |
| 控制服务 `internal/remote` | 主机登记、授权、签名短期票据、续租、撤销及审计 | 引用现有唯一 IdP/网络管理；不持有媒体帧 |
| 连接协调器 `internal/client` / Windows controller | 站点会话 + 目标设备 → 已批准网络通道；发布路径/断线事件 | 不将 NetBird 内部 Go 对象暴露给原生 UI |
| `packages/remote-core` | 已验证票据 + 双时钟 → 会话/能力/终止原因 | 纯 C ABI，不依赖窗口、GPU、媒体 SDK、套接字或后台线程 |
| Windows 用户会话主机执行器 | 门禁快照 → 采集/输入/音频工作者 | 每个敏感操作检查能力；停止后释放帧、音频、按键与文件临时状态 |
| `apps/windows/remote` | 指定显示器 → 同步借用 GPU BGRA surface | 只用 DXGI/D3D11；GPU/COM 句柄不越过平台层进入共享 ABI |
| 编码/传输/解码/渲染 | 有界帧或数据包 → 对端播放 | 独立适配；编码器不能创建第二套账号/配对/公网协调服务 |

Windows 主机身份与特权协调属于受限服务；采集/音频/普通输入属于交互用户会话代理。锁屏/UAC/用户切换单独设计、单独验收，不通过给 UI 管理员权限解决。Linux、Apple 的系统权限也不能由共享核心绕过。

## 3. 连接、恢复与终止的顺序

1. 客户端验证站点版本、证书和时间，再认证；协商双方真正实现的能力。
2. 服务端在同一事务检查账号、设备、主机授权、VPN 租约和并发上限，签发绑定双方及主机启动实例的短期授权。需要本地同意时等待主机用户操作。
3. 网络适配器只为批准的双方建立最小地址/端口策略。主机验证服务端签名及控制端持钥证明，并原子消费一次性票据。
4. 主机门禁通过后才启动被允许的工作者。观看不包含输入；当前音频和输入逐项取交集。剪贴板、上传、下载独立授权并逐命令检查，使用有界共享传输模块。能力不足返回稳定错误，不静默换成外部播放器或放宽授权。
5. 直连/中继变化只改变传输路径。短暂断线期间停止输入并释放按键；恢复需要重新验证通道绑定和当前租约。过期/撤销后使用新会话，禁止复活旧 generation。
6. 退出站点、切换站点、账号/设备/授权被禁用、主机重启、租约过期或用户拒绝时，先关闭敏感操作门禁，再取消采集/编码/传输及待发队列；释放按键，终止文件传输，回收网络授权，最后报告完成。

退出的本地执行必须立即开始；远端在线撤销目标为 5 秒内，通信中断时由最长 30 秒主机租约兜底，轮询不超过 100 ms。不能承诺断网两端“瞬时同步”，也不能仅靠客户端退出按钮或网关 nftables 撤销主机权限。双时钟回拨、挂起恢复、通知丢失均属于验收。

续期按最近的服务端授权序号推进，快照可领先或落后于对端 offer，不要求逐张精确相遇；每次仍验证签名、绑定、同一代次、递增序号、权限不扩大和有效期。输入单次文字最多 8192 UTF-8 字节，最多 128 事件 / 60 KiB 一批；平台通过共享核心取得上限，明确处理拒绝入队。移动端文字草稿显式发送，退格/回车以完整按键对提交。队列接受只表示入队，失焦、断线与陈旧输入不得重放。

## 4. 媒体复用的决策门槛

MiniRTC 保持候选，不能因为跨平台就默认打包其全部 SDK。必须先证明能够使用 NetGo 的身份、已批准传输路径、取消和租约，不额外运行上游账号/配对/信令服务器。不能禁用重复能力、跨层依赖过重或无法满足包体/许可要求时，替换为窄媒体适配，不推翻领域和 C ABI。

Windows 已接入 DXGI → D3D11 NV12 → Media Foundation 硬件编码，失败时明确软件回退。macOS 使用 ScreenCaptureKit → VideoToolbox，Linux 使用 X11 或 portal/PipeWire → GStreamer。Android/Apple 平台层管理 Surface/设备资源，共享层管理会话与包格式。

Windows/macOS 硬件路径不回读原始画面；Windows 软件回退和 Linux 管线可能经过 CPU。原始帧允许丢弃，已编码参考帧不得静默丢弃；在途编码、网络队列和文件分块均有上限。文件每块等待确认，共用 TLS 通道；独立 QoS、自适应码率和高时延性能仍需后续优化和实测。

## 5. 跨模块退出条件

| 编号 | 可重复场景 | 必须观察的结果 |
| --- | --- | --- |
| I01 | 有 VPN 权、无远控权；有观看权、无输入权 | 能访问获准 LAN；拒绝启动远控或注入输入；不分配无权工作者 |
| I02 | 同一站点 Windows↔Windows、Android→Windows | 原生内嵌画面/输入/音频；双方身份、票据、会话与路径记录对应 |
| I03 | 观看中降权、撤销账号/设备/授权、站点退出 | 门禁先关、队列丢弃、按键释放；记录主机最后敏感操作时间，不只查 UI |
| I04 | 强制直连→中继→直连；丢包/限速/换网 | 不重复配对、不扩大权限；队列/内存有界；记录中断与恢复时延 |
| I05 | 断开控制通道、暂停续租、时间回拨/挂起 | 最长本地租约内停止；恢复网络不能复活旧会话 |
| I06 | 复制票据、错误设备、错误主机启动实例、并发重放 | 在任何画面/音频/输入启动前拒绝；并发消费只有一个成功 |
| I07 | 主机锁屏、UAC、切换用户/屏幕、休眠、采集 access-lost | 明确暂停或重建同一批准目标，不误采另一用户/显示器，不残留按键 |
| I08 | 文件/剪贴板与高帧率会话同时运行并随时取消 | 内存/队列/并发上限有效；取消不死锁；不残留越权文件或剪贴板内容 |
| I09 | 客户端启动/退出、连续重连、72 小时 | 线程/句柄/内存无持续增长；帧耗时、CPU、RSS、包体有实测基线 |
| I10 | 空库安装 v2、旧版客户端、卸载重装 | 新库/接口一次切换；旧版明确拒绝；停止旧栈后按归属清理，无双写 |

I01–I10 尚未完成。门禁单元测试、采集探针、VPN 网络测试分别提供局部证据，三者相加也不能替代 I02 的真实端到端会话。

## 6. 当前接口与后续验收

- 概览和诊断轮询 `GET /netgo/v2/admin/summary`，只返回 counts、策略版本/错误与运行指标。账号、资源、设备列表使用 `GET /netgo/v2/admin/state?section=users|resources|sessions&after=<cursor>`，每页 50 项、响应 next_after；用户编辑加载资源选项，设备页保留租约及账号标签。远控授权页通过 section=remote 取得账号选择项。
- 管理状态不再包含 audit；通过 GET /netgo/v2/admin/audit?before=<sequence> 分页，每次最多 100 条，next_before 为 0 表示没有更早记录。
- 主机接受 windows/macos/linux、显式本地无人值守策略及实际实现的六项能力。登记必须提供每次启动生成的 transport_key；重启关闭旧会话。保留不可连接主机的状态和有效能力；客户端只允许 ready 状态发起连接。
- /netgo/v2/remote/key 已移除，授权响应包含 site_key；所有内置客户端同步使用这一响应。
- 未指定会话限额统一默认为 1；容量错误为 gateway_capacity_exceeded，不会撤销其他有效租约。
- 自动化回归覆盖竞态、容量、权限清理、审计分页、会话代次和媒体队列；真实画面、键鼠、音频、换网与长期稳定性按 I01–I09 分平台验收。

## 7. 本轮接口与生命周期约束（2026-11-26）

- `health.server_unix` 必填，Go、Windows、Web 使用相同范围校验。只支持当前 API v2/schema 3，不保留缺失时间字段的旧服务端回退。
- 设备删除先提交本地撤权：移除凭据、VPN 租约、被控登记、相关授权及远控会话。上游删除失败返回 HTTP 202 `{deleted:false,cleanup_pending:true}`，设备显示 `delete_pending:true`，禁止重新签发该设备凭据。后台清理独立于租约过期检查，每分钟扫描到期待重试项；单项超时 2 秒，失败按 1–32 分钟退避并继续处理其他项。账号删除采用相同的 202、delete_pending 和持久化重试语义，待删除账号禁止恢复权限；上游 404 视为成功。管理页区分已完成与待清理，支持手动重试。
- 认证事务只在实际注册的匿名路由限流：直接来源最多 90 请求/分钟、全局最多 900；本机 TLS 代理共享全局预算，不信任任意转发头。签名验证通过后的刷新按设备独立限制 12 次/分钟；账号失败尝试仍独立限制 5 次/分钟，成功登录不占失败预算。
- `GET /netgo/v2/remote` 只返回当前活动会话；`next_generation` 仍计入保留的历史会话。`GET /netgo/v2/admin/remote/history?before=<cursor>&limit=50` 返回 `{sessions,next_before}`，上限 100，管理员专用。created_at 为毫秒精度、不可变的创建时间；issued_at 是当前票据签发时间；closed_at 记录首次关闭，关闭后保留 24 小时。按 created_at 与 ID 组合倒序分页；next_before 为不透明游标，客户端原样回传，即使上页末行已清理仍能继续分页。控制凭据字段不对外返回。
- 已认证账号可建立没有 LAN 资源的 overlay 租约。空资源集合不会产生 LAN/互联网授权，桌面访问仍须独立远控授权与主机门禁。互联网出口继续单独检查。Go/Windows 本地状态新增 remote_ready，表示当前身份、租约和远控工作者就绪；所有平台远控入口、主机列表和停止逻辑使用该字段，与 LAN 网关路径独立。
- 主机允许 NetBird 管理 ACL 生效，保持默认拒绝；网络策略只授予获准控制端到主机指定 TCP 端口。未受管的启用策略仍阻止 NetGo 应用策略。不得用全局放行代替授权。
- 客户端清理超时保留旧 worker 的完成信号；旧 worker 结束前不能启动新连接。Android 文档选择器只暂停画面呈现并释放输入，普通退后台、退出或销毁仍停止远控。
- 后台策略核对独立于本地过期清理：本地版本变化及时处理，至少每分钟检查上游漂移，失败按 5–60 秒退避。数据库持久化层不拥有领域依赖清理规则，规则统一在 `model.PruneDependencies`。
- Windows 每个站点传输实例按候选复用 TLS 连接，30 秒空闲后重建；证书与规范 Origin 校验保持，失败连接丢弃，不自动重放写请求。引擎 RPC 使用一个受父进程 Job 管理的子进程逐行交换有界 JSON；断开、超时或取消销毁该子进程。
- 主机授权读取由控制监视线程完成，媒体线程只应用与会话 ID/票据匹配的短期快照；旧票据过期或监视失联仍立即关闭。文件传输最多 8 个分块在途，保持顺序、偏移、取消和完整性验证。
