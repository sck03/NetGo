# Windows 与 Linux 服务端重构记录

日期：2026-11-27（Asia/Shanghai）。基线 `532724e`。版本保持 **0.3.0-dev / API v2 / schema 4**。本轮按审查结果实施修复、精简和文档更新；仅执行与改动有关的必要检查，不做全平台验收。

## 修复和职责边界

| 问题 | 最终处理 |
| --- | --- |
| Windows 远控专用账号因空 LAN 资源连接失败 | NetBird RPC 接受空网络选择，清除旧选择；重复 CIDR 去重。保留 overlay 租约、远控及权限控制。 |
| 两个普通客户端各选各的中继 | 按受信 Profile 与 Management peer IP 区分网关链路，普通客户端使用一致选择；限制在 Management 发布端点。Go/Windows/移动适配同时传递拓扑。 |
| conntrack 清理期间租约过期，随后重新开放 | 在检查后取时间，在最终应用前重新生成规则和成员缓存。保留保护批次、作用域清理、失败关闭与 SQL 事务顺序。 |
| 管理页刷新 token 导致在途创建操作失效 | 并发读写请求与独占轮换分离；等待在途请求结束后刷新，新请求等待；登出取消，不重放修改请求。 |
| Windows 探测拖慢首个有效入口/断开 | TLS、连接、DNS及串行锁等待观察取消；取消败选探测，撤销清理使用独立 4 秒上限。 |
| 远控列表大于 IPC 限制 | 服务端每页 50 台，只加载相关依赖；客户端逐页读取并约束 cursor 和页数。响应统一 4 MiB，超限返回明确错误。 |
| 帧更新堆积及绘图阻塞采集 | 合并通知，保留最新已解码不可变帧，锁外绘图；压缩媒体流仍按协议顺序处理。 |
| 控制面瞬时错误直接终止 | 剩余 watchdog 窗口内重试传输错误，成功前不延长期限；丢失续租响应后重新读取 sequence。授权拒绝仍终止。 |
| 显示模式变化即断开 | 维持协商尺寸，重建采集/编码资源，采集丢失最多恢复 3 秒；期间释放按键并停止输入。需实机确认驱动行为。 |
| UI 配置、数据契约容易漂移 | Windows 偏好解析/保存独立模块，类型错误安全回到默认；Go 生成远控、分页和运行状态 TypeScript 类型。 |

移除缺省候选类别兼容分支、Windows 旧偏好推断和原生管理员列表全量装载。保留 CLI 密码重置、证书、备份及防火墙所有权检查：这些是独立运维职责或系统防火墙格式适配，不是无效旧业务代码。

服务端续租仍扫描活动网关成员；未为减少耗时移除防火墙检查或把外部授权写入移出事务。这里仍是随租约数量增长的开销，不能据此声称整体续租已达到常数复杂度。

## 本轮验证

- Go 1.27.4：gateway/session/store/remote/client/engine-netbird/contracts/api 定向 race 测试通过；改动相关包 vet 通过。
- 上游补丁：Relay 选择、站点隔离/拓扑校验、空路由及重复 CIDR 的定向测试通过；4 项补丁工具检查及完整源码一致性核验通过。
- 前端：15 项相关测试、vue-tsc 和 Vite 构建通过。JS 122.11 kB / gzip 43.46 kB，CSS 11.32 kB / gzip 3.31 kB。
- Windows：使用固定 OpenSSL 4.1.0、JSON 3.12.0 构建 NetGo.exe，最后编译产物 7,359,488 字节（约 7.02 MiB）；native-core/native-ipc/remote-client/remote-host/remote-watchdog 定向 CTest 通过。最后补充偏好/分页修改后重跑相关 3 项 CTest，通过。TLS 回环检查覆盖证书身份、时钟、多入口、败选取消、在途请求取消和清理隔离。

没有进行完整测试、Linux 内核实机检查、跨设备全媒体、72 小时压力测试或其他未持有设备的验收。Windows 显示恢复需实际显示器/显卡验证。登录前/UAC 桌面、完整多屏/旋转、自适应码率仍属未完成能力。
