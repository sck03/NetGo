# 运行与维护

本手册对应 0.3.0-dev、API v2 和数据库 schema 6。schema 6 增加过期清理索引，使用单写／有界只读连接；保留持久化创建预留及独立于活动身份的远控历史。schema 1–5 数据库会在修改前被拒绝，需要新目录初始化；项目未部署生产，不提供迁移或双写。未知业务数据不会由安装器自动删除。创建结果不明时后台保留预留并核对上游，请勿重复创建；管理概览显示未完成任务数。

上游账号创建后，本地提交前持久记录清理任务；本地授权检查失败且上游删除不可用时，后台按退避重试，服务重启后继续。重试先检查本地是否已提交该账号，已提交则仅移除任务；上游返回 404 视为清理完成。该任务与用户授权记录独立。上游返回新 ID 前连接中断、或本地磁盘无法写入时不能承诺跨系统原子提交；失败日志仍需保留排查。

## 普通用户入口

- Windows：安装版双击 Setup；绿色版解压后打开 NetGo.exe。账号、站点导入、VPN、互联网模式和远控都在客户端操作，首次网络授权由程序发起。
- Linux 桌面：打开 netgo-desktop，首次连接通过系统图形授权安装独立网络组件。连接服务和网络 daemon 由程序管理，不需要分别运行后台程序。
- Android：使用客户端 APK；macOS 使用 NetGo.app；iPhone/iPad 使用带 Packet Tunnel 扩展的客户端。Apple 设备安装和 VPN 权限需要有效签名。具体构建、签名和未验收范围见 [独立构建说明](BUILD_CLIENTS.zh-CN.md)。

客户端连接前导入管理员导出的站点 JSON。密码和设备密钥不进入导出文件。自动同步仅接受同一站点身份的递增配置；地址主机或 CA 更换需要明确确认管理员提供的新文件，旧版本和同版本冲突仍被拒绝。

服务器初始化时允许网关 IP 暂未分配，但导出客户端文件前必须完成网关登记。管理 API 在此阶段返回 `503 site_not_ready`，网页显示初始化提示。保存的登录凭据绑定协议、站点 ID、规范化的 HTTPS 主机名和 CA；更换信任来源要求重新登录，同主机端口、候选地址及显示名更新不清除凭据。没有绑定信息的开发期旧凭据不再复用。

## LAN 服务端与 VPS

两类节点分别安装，运行维护统一使用 Go，最终用户不需要 Python、Node 或 Go 编译器。

LAN 首次执行平台包内 install-server.sh，之后输入 **ng**；VPS 使用 install-vps.sh，之后输入 **ngv**。各自菜单提供初始化/导入、状态、端口、证书、诊断恢复及卸载。安装包、下载校验、证书格式和离线参数见 [安装与维护说明](INSTALLERS.zh-CN.md)。

LAN 保存账号、权限、站点 CA 签发密钥和控制数据库。VPS 只保存节点配置和通信所需密钥；frps 提供备用控制隧道，Relay/STUN 提供 VPN 中继。LAN 只需要 frpc，运行包不包含 frps。

修改设置前由维护器保存受保护备份，校验配置和证书，然后重启受管服务并等待其就绪。失败时恢复原配置和服务；恢复仍使用递增配置版本。安装器拒绝接管外部修改的服务单元、快捷命令或路由/防火墙规则。

## 旁路由与资源授权

在 ng 菜单设置 LAN 网卡/网段、旁路由 IP 和 DNS。例如网关和 DNS 均为 192.168.19.254，掩码 255.255.254.0 时，所在网段为 192.168.18.0/23。自动检测到 Clash/Mihomo Fake-IP 时启用专用 198.18.0.0/15 支持。

在管理页创建“互联网（旁路由）”资源并授予指定账号。只有被授权的账号可通过该出口访问互联网，客户端开关只选择已授权能力。LAN 地址/端口权限单独授予，互联网权限不开放整个私网。

服务器使用独立 VPN 入站策略表；服务器默认网关和其他业务不随旁路由设置改变。撤权会撤销租约、清理对应连接，并由内核期限继续保证失效。当前互联网配置针对 IPv4；IPv6 LAN/出口须另外实现和验收。

## 时间与有效期

不要求客户端与服务端时钟相差小于 30 秒。客户端验证 TLS 和站点身份后，以服务端时间为基准，并使用单调时间计算经过时间。请求签名、刷新和租约到期采用这一基准；修改客户端系统时间不会延长已建立会话。

防重放 nonce、服务端签名请求期限、会话到期及证书验证仍保留。服务端正常校时有利于证书和审计时间记录；秒或分钟级客户端偏差不再成为连接前的硬性阻断。

## 卸载与故障排查

在 ng/ngv 菜单选择卸载，或者使用 ng uninstall --yes / ngv uninstall --yes。只移除本项目受管服务、快捷命令和规则，保留程序、配置、身份、证书和数据以供重装。不会清理系统包、SSH、Docker 或其他应用。

先查看客户端错误、节点菜单状态和诊断恢复。私有命令诊断、配置备份和节点 ZIP 可能含通信密钥，应只保存在受保护位置；不要提交 GitHub。公开问题报告可使用脱敏的管理诊断。

## 开发验证

Go、原生 C/C++、前端和开发打包工具各自执行适用检查。Python 是开发构建/测试工具，不是最终节点维护依赖。脚本与工作流按平台分开，版本固定在稳定版锁文件；校验成功后使用相应平台产物。

构建、单元测试、Xvfb/模拟器启动及局部实机测试不等于完整平台验收。最新状态见 [进度](PROGRESS.zh-CN.md) 与 [本轮报告](https://github.com/sck03/NetGo/blob/cc36472058c310b7812089df60abdcc5d513e625/docs/REFACTOR_2026-11-27.zh-CN.md)。开发缓存清理见 [构建说明](BUILD_CLIENTS.zh-CN.md)，运行中的引擎及身份配置不属于自动清理对象。

## 本次接口与故障处理（2026-11-25）

管理审计通过 GET /netgo/v2/admin/audit 分页读取，响应包含 events 和 next_before；使用 before 游标读取更早记录。/admin/state 不再返回完整审计历史。

网关全局上限为 1024 个租约且序列化请求不超过 1 MiB，超限返回 gateway_capacity_exceeded 并保留现有连接。账号删除先撤销本地访问，再调用身份/网络管理端；上游不可达时，管理页保留禁用账号，可在恢复后重新删除。

重连使用客户端控制器保存的最新站点配置，显式导入才允许用户确认新信任。不得把清空客户端身份或允许旧配置回退作为重连修复。完整变更与测试边界见 [重构记录](https://github.com/sck03/NetGo/blob/cc36472058c310b7812089df60abdcc5d513e625/docs/REFACTOR_2026-11-25.zh-CN.md)。
