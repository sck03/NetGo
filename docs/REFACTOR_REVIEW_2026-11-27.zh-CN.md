## 修复与模块边界

| 问题 | 当前实现 |
| --- | --- |
| 停服后在途申请重新开放网关 | `session/lifecycle.go` 的 Close 持久保持停止状态；所有授权写入在同一互斥边界检查。先取消服务上下文，再关闭授权和 HTTP；HTTP 排空超时后关闭连接。网关清理错误向上传递，Close 可重试但 Reset 不会重新开放管理器。 |
| 空集合导致管理页崩溃 | `model.Array` 保证资源 ports、账号 resources、租约 resources 输出 `[]`。Go DTO 生成 `packages/ui/models.generated.ts`，漂移由 Go 契约测试检查；管理请求使用泛型与 unknown，移除宽泛 any。共享 ICMP 响应样例同时约束真实资源写入、持久化读取和 Vue 渲染/编辑。 |
| 异常退出遗留上传文件 | `exchange_lock.hpp` 用 OS 文件锁约束同一目录的上传和回收。崩溃后锁由 OS 释放；启动和新传输只回收名称匹配、可安全打开的 `.netgo-<token>.part`。固定锁文件不删除，其他普通文件包括隐藏文件计入配额；正在上传的目录不能被第二个实例回收。 |
| 刷新认证期间取消失效 | Go `auth_gate.go` 支持并发普通请求、独占凭据轮换、可取消等待，并优先等待中的刷新。Go 刷新含锁等待共 4 秒；Windows 凭据锁等待和刷新 HTTP 各有 4 秒上限，并检查断开/放弃信号。保持旧请求完成后再换凭据的顺序。 |
| Android 初始化失败泄漏 | 编解码器、音轨在可能失败的配置/启动前移交字段，统一释放停止与资源句柄；重复格式初始化也释放前一次媒体对象。上传暂存独立到 `RemoteUpload.kt`，协程取消及所有权转交失败会删除暂存文件。 |
| iOS 停止排在慢远控请求之后 | `TunnelRequestQueue.swift` 承担最多 2 个执行、8 个未完成消息；停止直接拒绝新消息并取消 Go 连接，再由生命周期队列收尾。已排队消息仍收到结束响应；桥接持有稳定客户端引用，并防止停止信号丢在初始化过程中。启动失败关闭隧道描述符。 |
| Linux 帧呈现重复复制、缺少查看选项 | `frame_presenter` 让 GBytes 持有共享不可变像素的所有权，省去呈现阶段两次完整帧复制，继续合并 UI 呈现任务。增加“本次仅查看”，与其他端一样收窄键鼠输入；文件和剪贴板继续依照独立授权。 |
| Windows UI 混入线程和 IPC 生命周期 | `ui_worker` 独立管理有界请求与结果、取消 IPC 和线程收尾。窗口消息不再传递裸堆指针；关闭时回收尚未消费的结果。 |
| 清理重试信息缺少前端入口 | 账号和设备共用 `CleanupStatus.vue`，显示失败次数和下次重试时间；后端计数上限为 6，页面明确显示“6 次及以上”，不当作完整历史次数。 |

续租持久化移入 `store/lease_renewal.go`，移除旧的全依赖快照读取。只解码当前凭据、账号、设备、授权资源及目标租约，只更新一条租约；网关成员依然在同一 SQL 写事务内核对和应用。失败回滚后清空访问并报告清理错误，撤权期间缺失凭据仍返回 unauthorized。移除不再有其他调用者的会话存储回调包装。

没有把 nftables 调用移出事务，也没有引入未经 Linux 内核验证的增量规则替换。网关成员扫描及刷新仍随活跃租约数量增长，不声称整个续租路径为固定开销。

## 续租基准

同一 Windows 主机、相同 Go 工具链和内存 SQLite；相同的 16/128/1024 活跃租约样本，只延长一条租约。旧实现使用原审查副本，当前实现使用 `BenchmarkVPNRenewActive`；每档各测两次、每次 300 ms，表中为均值。无实际网关 IO、HTTP、磁盘同步；B/op 为累计分配量而非常驻内存。

| 活跃租约 | 原实现 ms/op | 当前 ms/op | 原实现 B/op | 当前 B/op |
| ---: | ---: | ---: | ---: | ---: |
| 16 | 0.620 | 0.423 | 125,392 | 29,686 |
| 128 | 2.608 | 1.704 | 890,926 | 158,079 |
| 1024 | 20.132 | 12.347 | 7,185,815 | 1,358,195 |

1024 样本下耗时约减少 38.7%，分配量约减少 81.1%。Linux 的帧优化是可从所有权代码确认的复制次数减少，尚未测量设备实际帧率和显存/内存峰值。
