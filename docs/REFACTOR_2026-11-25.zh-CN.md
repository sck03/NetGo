## 已实现的改动

| 问题 | 实现与边界 |
| --- | --- |
| 管理登录刷新竞态 | 请求绑定登录代次和发出时的 token；旧 token 的 401 等待正在进行的刷新，只有当前凭据被拒绝才退出；覆盖刷新响应前后两种交错 |
| 远程会话替换随机失败 | 写入新会话前先持久化旧会话的 closed 转换，保留 SQLite 单主机活动会话唯一约束；128 次连续替换回归 |
| 删除资源留下无效账号权限 | 同一事务清理用户资源引用，按资源范围撤销 VPN 租约，不撤销其他用户的无关连接 |
| 容量不足误断全部连接 | 服务端与特权 helper 共享 1024 租约、1 MiB JSON 上限；超限在修改网关之前拒绝，返回 gateway_capacity_exceeded |
| iOS 配置回退 | 显式导入带操作 ID 和持久化回执；重连使用控制器已保存的配置；界面同步 /desktop/profiles，保留版本和信任校验 |
| 原生端取消和迟到结果 | Linux 独立断开通道；Android 服务自有初始化生命周期；Android/Apple 连接与列表结果带代次隔离；后续清理不会误断新连接 |
| 远控结束导致主机共享关闭 | 主机心跳与单次会话拒绝分离；迟到拒绝只影响对应代次；会话检查单独限时，清除绑定后再向服务器撤销 |
| 界面适配缺失 | Android/Apple/Linux 展示已授权但不可连接的主机及状态、资源列表与替换其他连接选项；Web 补齐用户名/角色编辑 |
| 声称了尚不能执行的能力 | 当前被控主机限定 Windows + 本地同意；可授权能力限定观看、输入、音频。剪贴板、上传、下载位仅作为底层协议扩展保留，服务端拒绝当前产品授权 |

## 模块与资源约束

- 新增 internal/accounts 领域服务，HTTP 层负责输入/输出；账号创建和删除的上游 IO 不再持有 SQLite 写锁。删除先撤销本地权限；上游失败时保留可重试的禁用账号，404 视为上游已经删除。
- Store 提供索引身份/用户名查询、管理/策略/远控窄快照和远控事务。普通事务不加载历史审计；审计按 sequence 游标分页，每页至多 100 条，数据库保留最近 10000 条。
- State.Clone 明确复制可变集合，替代完整 JSON 序列化深拷贝；策略变化按领域结构比较，避免非策略写入导致重复同步。
- 网关应用仍与数据库提交处于同一安全临界区。这是为了防止权限撤销与安装新访问规则交错；不能仅为减少锁时间把网关操作移到提交边界之外。容量拒绝与实际网关失败采用不同处理，实际应用/提交失败仍关闭访问。
- 控制连接按入口复用有界 HTTP 连接池；配置更新、断开和失败路径清理空闲连接。签名请求禁止自动重放请求体。
- Reconciler.Ensure 对 2 秒内相同策略和相同管理端 peer 成员合并工作；周期 Apply 仍完整检查外部漂移，新 peer 不会被缓存遗漏。
- 管理端审计单独分页；隐藏页面停止轮询，编辑列表按需更新，远控页面独立刷新。
- Windows 媒体发送改为单线程拥有的增量输出，单轮最多 8 × 16 KiB，队列最多 64 项且总计不超过 8 MiB，单包期限 3 秒。积压时跳过尚未编码的新视频帧，不丢已编码参考帧；输入继续轮询。NV12 帧缓存复用，码率按尺寸和帧率限制在 0.8–6 Mbps。
- Android 解码输入最多等待约 30 ms，不能提交时明确结束会话；音频保留未写完的余量，限制为 19200 字节。Apple 通过串行同步入口对原生工作线程施加背压，音频至多 8 包；停止后清空参数集、音频计数并隔离旧帧。
- 移除无调用的 Manager.Mutate、Store.Snapshot 和冗余 /remote/key 请求；共享查看器直接使用经认证的授权响应 site_key。保留 nftables 归属判断等当前系统差异处理。

## 本地验证

Windows 上使用项目锁定的 Go、Node、CMake/MinGW 和 Android SDK。已执行的检查及后续云构建结果记录在本文末尾，不能将未执行设备场景写成通过。

可复现命令：

```text
go test -race ./internal/... ./cmd/...
go vet ./internal/... ./cmd/...
node --test tests/frontend/*.test.mjs
npm run build
cmake --build .cache/native-build --parallel 2
ctest --test-dir .cache/native-build --output-on-failure --timeout 60
python -B -m unittest discover -s tests/tools -v
python -B scripts/build-android-client.py --sdk <Android SDK>
go test ./internal/store -run '^$' -bench BenchmarkReadPaths -benchmem
```

读路径测量：Windows amd64，i5-9400F；内存 SQLite，200 用户/设备/凭据及 10000 条审计。当前领域全量快照约 5.21 ms、422750 B/次、6253 次分配；索引身份查询约 0.125 ms、1949 B/次、37 次分配；100 条审计页约 0.384 ms、57216 B/次。这里比较同一版本的查询路径，不是整体服务器吞吐、生产压测或跨平台性能承诺。
