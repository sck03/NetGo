# Windows 客户端

0.3.0-dev 使用原生 C++/Win32 窗口。默认客户区 520×370 逻辑像素，随 Windows DPI 缩放；主界面集中显示服务器、账号、密码和连接操作。

日常只有一个入口 **NetGo.exe**。同一程序通过内部 `--agent` 和 `--remote --site` 模式运行连接后台与远控窗口，主界面负责自动调用；用户无需输入这些参数，也不必分别运行三个 EXE。后台使用独立进程保留取消与故障隔离，代码仍按平台/连接/会话/媒体静态库划分。统一程序当前约 6.70 MiB，预算 10 MiB，仅导入系统 DLL；OpenSSL 静态链接。网络核心和 Wintun 作为受限系统网络服务安装，不能合并成普通用户进程。

安装版双击 Setup，安装后从开始菜单打开 NetGo。绿色版解压后双击 NetGo.exe；首次连接所需的管理员授权由“准备网络服务”入口发起。绿色版根目录不暴露后台/远控程序或 PowerShell 脚本，辅助网络安装器放在 `.netgo`。站点和设置放在目录内 `data`；密码与设备密钥由 Windows Credential Manager 按目录/站点隔离。

## 首次连接

1. 按 [独立安装入口](INSTALLERS.zh-CN.md) 在预期桌面用户下安装一次网络服务；日常打开 NetGo 无需管理员权限。
2. 在“连接”页点击“导入”，选择管理员导出的站点 JSON。核对控制网址和证书来源。
3. 输入账号、密码，点击“连接”。勾选“记住密码”后，仅成功连接的凭据写入当前用户的 Windows Credential Manager，按站点隔离。
4. 进入“可访问资源”页查看获准的 IP/网段、协议和端口，再访问对应的 NAS、远程桌面或服务。VPN 权限不替代目标设备本身的账号。

连接过程中按钮用于取消；连接后用于断开。已有会话冲突时，确认需要替换后勾选“替换旧连接”。取消和断开会清理本次隧道；若提示清理失败，先恢复 NetGoNetBird 服务并再次断开。

## 页面与配置

| 入口 | 功能 |
| --- | --- |
| 连接 | 服务器选择、账号密码、显示密码、记住密码、替换会话、连接/取消/断开 |
| VPN 信息 | 控制入口、数据路径、虚拟地址、接收/发送流量及详细错误 |
| 可访问资源 | 当前租约获准的网段/主机、协议与端口 |
| 日志 | 自动刷新连接事件、手动刷新、清空日志和导出脱敏诊断 |
| 配置菜单 | 新建/编辑普通表单、导入/导出、高级配置、删除站点、忘记密码 |
| 远程桌面 | 网络连接成功后选择获准主机；仅观看授权不会请求输入权；允许本机被控需要显式开启及逐次本地同意 |

新建或编辑优先使用普通表单，填写管理员提供的名称、站点 ID、HTTPS 控制网址、直达主机:端口和路由虚拟 IP。多 WAN、备用入口及配置版本使用高级配置；受保护的已导入站点不能通过修改域名或 CA 冒充同一身份。配置导出不包含密码、令牌或私钥。

## 托盘和自动连接

关闭窗口默认保留托盘。托盘菜单可打开窗口、断开或退出；退出会先关闭当前连接和后台。选项菜单可设置登录 Windows 后启动、最小化到托盘和关闭时保留托盘。

自动连接绑定到明确选定的服务器。先勾选“记住密码”并成功连接一次，再启用“启动后使用已保存凭据连接”。没有保存凭据时不会隐式保存密码。要彻底停止自动连接，取消此选项；“忘记保存的密码”只清理当前站点的保存凭据。

快捷键：Ctrl+N 新建，Ctrl+O 导入，Ctrl+E 编辑，Ctrl+L 日志，Ctrl+Q 退出。Tab 在可见控件间切换，连接页回车执行当前连接按钮。

## 验证范围

统一 EXE 已通过原生核心、IPC、共享票据、C ABI、真实 TLS/持钥证明及观看权限测试；程序、窗口、托盘与快捷方式已接图标。Windows DXGI/H.264 本地编解码有实际记录，WASAPI 音频已编译接入。仍需两台设备的 overlay 画面/输入/音频、安装卸载、Windows 11、锁屏/UAC、多屏、休眠和持续运行验收；剪贴板与文件适配尚未实现。不能把“可编译”标为 Windows 全部完成。
