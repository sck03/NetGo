# Windows 客户端使用说明

当前客户端为 0.3.0-dev 开发版。日常只有一个入口 **NetGo.exe**：主界面自动管理连接后台、网络准备及远控窗口。Windows 的完整跨设备远控、UAC/锁屏、多屏和长期运行仍待验收。

支持“配置 → 新建服务器”手工填写，也支持导入站点 JSON。**导入不是必选步骤，新建窗口可以保存真实参数并直接连接。** 两种方式建立的是同一种站点配置；新建／编辑窗口直接支持多个直达入口、VPS 入口、VPS 中继和配置版本。

## 内网地址与外网访问

`192.168.18.220` 属于私有地址，同一局域网可以连接，互联网不能直接路由到它。它可作为站点证书身份和 LAN 入口；外网必须另有公网直达入口（路由器端口映射）或已配置的 VPS 控制转发。客户端在 VPN 建立前就需要可达的控制入口，不能指望先通过这个 VPN 去访问唯一的内网控制入口。

`ng → 3) 设置外网访问 → 管理 LAN / 公网直达入口` 可以管理多个直达地址，保持站点网址和证书不变；`ng → 3) 设置外网访问 → 配对 / 管理 VPS` 配置 VPS。导出新的站点文件给客户端。Windows 手工填写时，多个入口用空格分隔；已有站点填写管理员提供的新配置版本。修改证书身份仍须导入新身份。

## 安装与首次连接

1. 从 [Windows client 工作流](https://github.com/sck03/NetGo/actions/workflows/build-windows-client.yml) 最近一次成功运行下载 Artifacts。解压外层归档，在 `dist/windows-client/` 找到 Setup 和绿色 ZIP。
2. 安装版双击 Setup，之后从开始菜单打开 NetGo；绿色版解压后打开 NetGo.exe。首次 VPN 网络授权由程序发起，按系统提示授权即可。
3. LAN 管理员在 `ng → 4) 添加客户端` 中导出 `NetGo-site.json`，发给客户端用户。当前公开配置也保存于服务端 `/etc/netgo/client-site.json`。
4. 在 NetGo 主界面点击“导入”，选取该 JSON。它包含公共 CA、入口、VPN 网关及中继信息，不包含账号密码、令牌或私钥。
5. 选择导入的服务器，输入管理员分配的账号和密码，点击“连接”。“通过旁路由访问互联网”默认关闭，只有获得对应账号授权后才能启用。

配置文件来自同一站点时，程序会核对版本和身份。管理员更换控制主机或 CA 后，应重新导入其提供的新文件，并确认身份变更。已经导入的 ID、控制身份和 CA 受保护，不能随意在编辑框里替换。

## 截图中的“新建服务器”怎么填写

手工新建时按下表填写并保存，再输入账号密码连接。直达与 VPS 入口均可在普通表单填写。表单里的 `site1`、`control.example.com`、`100.96.0.1`、`relay.example.com` 都是示例，不能直接保存当作真实配置。导入文件可以省去逐项填写，使用者可自行选择。

| 字段 | 内容和来源 | 不应填入的地址 |
| --- | --- | --- |
| 显示名称 | 自定义，例如“家里的服务器” | 不承担站点身份校验 |
| 站点 ID | LAN 导出文件中的 `ID`，必须与服务端相同 | 不要自创 ID 或默认沿用 `site1` |
| 站点网址 | 导出文件中的 `Origin`，例如 `https://192.168.18.220:10443` 或站点控制域名 | 不因使用 VPS 而改成 VPS IP、Relay URL 或 SSH 地址 |
| 直达入口 | `Candidates` 中 `Kind: direct` 的控制入口，格式 `主机:端口` | 不填 Relay 端口、STUN 端口或 VPS 的 frps 隧道端口 |
| VPS 入口 | `Kind: auxiliary` 的公网控制转发入口，多个主机:端口用空格分隔 | 不填未配置转发的普通 VPS 地址 |
| VPS 中继 | 服务端导出的 `AuxiliaryRelay` | 不用它代替控制入口 |
| 配置版本 | 管理员提供的 `ConfigRevision` | 不使用较旧版本覆盖现有配置 |
| 路由虚拟 IP | 导出文件中的 `GatewayIP`，即 LAN 路由节点的 VPN 内部地址 | 不填 LAN 服务器的 `192.168.*` 地址、VPS 公网 IP、旁路由 IP 或客户端自身 VPN IP |
| 证书信任 | 导入站点 JSON 会携带公共 CA；手工配置时可导入管理员给的公共 `ca.crt`/`pem` | 不导入 `ca.key`、服务器私钥或完整 VPS 配置 ZIP |
| 本地中继 | 导出文件中的 `LocalRelay`，填写 LAN Relay 主机名或 IP，例如 `192.168.18.220`；只用于本地路径识别 | 不加协议、端口，不填 VPS IP 或旁路由 IP |

“使用系统信任”表示使用 Windows 的证书信任。私有 CA 站点若尚未导入对应公共 CA，不能只保留这个选项。导入管理员提供的站点 JSON 会自动解决客户端所需的 CA 配置；管理浏览器的系统信任需另外设置。

### 站点网址为什么不改成 VPS

站点网址标识始终提供账号、权限和服务的 LAN 站点。客户端通过“直达入口”或“备用入口”决定实际连接到哪台机器，仍校验同一站点身份。

举例：

| 项目 | LAN 内连接 | 经 VPS 从外网连接 |
| --- | --- | --- |
| 站点网址 | `https://192.168.18.220:10443` | 仍为 `https://192.168.18.220:10443` |
| LAN 直达入口 | `192.168.18.220:10443` | 保留，连不上时自动尝试备用入口 |
| VPS 备用控制入口 | 站点文件可同时包含 | `203.0.113.10:24443`，`Kind: auxiliary` |
| 本地中继标识 | `192.168.18.220` | 仍标识 LAN Relay |
| VPS 中继标识 | 来自服务端配置 | `rels://203.0.113.10:28443`，位于 `AuxiliaryRelay` |

`203.0.113.10` 是文档示例 IP。你的真实值以管理员导出的 JSON 为准。外网 PC 的浏览器未必能直接打开 LAN 私有站点网址，但客户端可以通过已经导入的 VPS 备用入口连接该站点。

VPS 入口和中继可在普通新建／编辑表单填写，也可以导入配置。管理员先在 LAN 的 `ng → 3) 设置外网访问 → 配对 / 管理 VPS` 中配置 VPS 并完成隧道部署，再用 `ng → 4) 添加客户端` 生成站点 JSON。填写 VPS 地址本身不会创建转发服务；客户端字段对应 `Candidates` 中的 `auxiliary` 和 `AuxiliaryRelay`。

独立端口模式下，VPS `24443` 用于客户端备用控制，`27000` 用于 LAN 与 VPS 之间的隧道，`28443` 用于 Relay。不要将它们混填到“直达入口”。本地/VPS Relay 的实际连接地址和端口由服务端下发，“本地中继”本身不创建中继，也不决定选择哪台中继。

## 连接与权限

连接过程中按钮可取消；连接后用于断开。已有会话冲突时，仅在需要替换当前账号旧会话时勾选“替换旧连接”。

“可访问资源”显示获准的 IP/网段、协议和端口。连接 VPN 不会自动开放所有局域网设备，VPN 权限也不替代 NAS、SSH 或目标设备本身的账号。

旁路由 IP/DNS 在服务端设置，例如 `192.168.19.254`。管理员还须授予账号“互联网（旁路由）”资源；客户端开关只选择已授权能力。旁路由地址不填到新建表单的 VPN 网关或中继字段。

客户端采用可信服务端时间计时，不再因本机和服务端相差 30 秒而拒绝连接。证书有效期、签名、防重放和会话期限仍会检查。

## 页面与常用操作

| 入口 | 操作 |
| --- | --- |
| 连接 | 服务器、账号、密码、记住密码、替换会话、互联网模式、连接/取消/断开 |
| VPN 信息 | 实际控制候选、VPN 数据路径、虚拟地址、流量和错误 |
| 可访问资源 | 当前账号获授权的网络、主机、协议和端口 |
| 日志 | 查看连接事件，导出脱敏诊断 |
| 配置 | 导入/导出站点、手工新建/编辑、高级配置、删除和忘记密码 |
| 远程桌面 | 主机状态、仅观看、电脑声音、全屏与停止；完整跨设备验收尚未完成 |

勾选“记住密码”并成功连接后，凭据才写入当前 Windows 用户的 Credential Manager。启用自动连接前先成功保存凭据；忘记密码可从配置菜单操作。

关闭窗口默认保留托盘。托盘可打开窗口、断开或退出；退出会关闭当前连接、远控子进程和后台，保留用户已选择的下次登录恢复设置。主动关闭远控窗口或点击共享的“停止”会关闭无人值守恢复。安装版在系统“已安装的应用”中卸载。绿色版的网络准备器位于 `.netgo`，由主界面调用；普通用户不需要手工运行维护脚本或后台程序。

快捷键：Ctrl+O 导入、Ctrl+N 新建、Ctrl+E 编辑、Ctrl+L 日志、Ctrl+Q 退出。

### 使用远程桌面

1. 双方先连接同一站点的 VPN。被控电脑在远程桌面窗口点击“允许本机远控”，管理员在网页远程桌面页给账号授权。
2. 控制方选择已授权主机。列表保留忙碌、失联、VPN 未连接和共享关闭的状态；只有可连接主机才能点击连接。
3. 连接前可勾选“仅观看”，并选择是否“收听电脑声音”。最终能力取账号授权、主机支持与本次选择的交集；取消音频后不建立播放流。
4. 对方同意后显示画面。F11 或工具栏按钮切换全屏，画面保持比例；F11 留在本地，切换前释放远端已按下的键鼠。点击画面后才向远端发送键鼠。
5. 点击“停止”或关闭窗口结束本次查看或共享。每次新来访都需本机同意；15 秒未确认会拒绝。

管理网页负责授权和停止会话；远程画面在原生客户端打开。完整跨设备画面、键鼠、音频与新工具栏的实际交互验收范围见最新验证报告。

## 排错

- `site_identity_mismatch`：站点 ID 与服务器不同，重新导入管理员提供的文件。
- 证书错误：检查站点网址是否被改成 VPS、公共 CA 是否已导入、系统日期是否在证书有效期内。
- 无法连接控制服务：核对控制入口端口；外网使用 VPS 时检查站点 JSON 是否包含备用入口。
- `internet_forbidden`：账号没有互联网资源授权，关闭互联网选项或由管理员授予权限。
- 一直“协商中”或无法识别数据路径：确认 VPN 网关及中继标识来自服务端，不是表单的示例值。
- 配置版本冲突：获取服务端最新导出文件；普通编辑不能绕过配置版本或证书保护。

构建与实机边界见 [本轮验证报告](REFACTOR_STABILITY_2026-11-27.zh-CN.md)；LAN/VPS 安装步骤见 [安装说明](INSTALLERS.zh-CN.md)。

## 当前连接与恢复行为

普通“新建服务器”使用配置版本 0，仅用于首次引导。连接成功后自动接收服务端正式版本、入口、网关和 DNS；已有正式配置仍拒绝回滚和同版本修改，不允许通过重新填 0 绕过保护。

Agent 异常结束后，后台状态查询会检查单例进程并尝试恢复；界面线程不等待启动。选择退出时也会先恢复缺失的 Agent 并清理网络。存活但无响应的 Agent 或网络清理失败会显示错误，不会把失败当作安全退出。引擎 IPC 的锁等待、写入、读取共享 25 秒期限，取消可中断管道等待。

远控窗口按站点隔离。切换站点会关闭旧子进程后打开对应站点窗口，关闭过程由计时器管理；应用退出和切换站点保留无人值守偏好。

仅使用远控的账号可在没有 LAN 资源时连接；互联网资源未选中时也不会因为空路由列表而退出。远控主机列表按页读取，界面继续保持原有主机选择、权限与状态展示。

取消连接会中止候选探测和正在等待的 HTTP/TLS 请求；选中有效入口后取消其他探测。断开时的在线撤销有独立 4 秒上限，服务端租约到期仍是失联兜底。

远控控制面短暂失败只在原有 6 秒 watchdog 内恢复；授权已撤销、取消或期限已过时直接结束。显示模式变化会保留协商的视频尺寸并重建编码器，采集丢失最多重试 3 秒，期间释放已按下的键鼠并停止新输入。该恢复逻辑已编译，本轮未完成显示器/驱动实测；旋转显示、登录前桌面、UAC 安全桌面及完整多显示器仍不在支持范围。

窗口线程只持有最新已解码帧的共享只读引用；绘制在锁外执行。偏好设置采用独立的类型校验模块；损坏设置回到默认值，不因字段类型错误导致启动退出，也不根据旧的缺失字段猜测自动连接站点。

“使用已保存凭据自动连接与恢复”允许程序在临时断网或租约过期后重新认证，以新代次获取新租约。主动断开、账号被拒绝或其他设备的会话冲突不会自动重试或抢占。恢复使用 1–30 秒有界退避；关闭设置、取消或退出可终止恢复。

无人值守恢复与开机启动、自动连接统一保存在 `.preferences`。启用无人值守会启用这两项依赖；关闭任意依赖会同时关闭无人值守恢复。主窗口与远控窗口通过受锁保护的更新入口修改各自字段，避免覆盖另一窗口的设置。旧 `.remote-unattended` 不再读取，不做旧开发版迁移。

远控会合成系统独立绘制的远端光标；输入模式下隐藏画面区域的本地重复光标。声音设备不可用时保留画面并显示提示。文件操作使用有界工作队列，授权撤销后丢弃无权结果，文件发布前重新检查权限。GPU 编码采用最多 8 个样本的资源池；显示驱动行为仍待实测。

本轮检查范围与限制见 [重构记录](REFACTOR_STABILITY_2026-11-27.zh-CN.md)。

查看端文件 IO 使用独立工作线程，文件命令超时只取消当前传输，媒体和后续命令可继续。画面解码复用缓冲；软件编码在源分辨率变小时可放大到初始画布。会话中宽高比改变会拉伸到固定画布，重新连接重新协商；GPU 查看、动态码率、多显示器和 UAC 桌面未在本轮实现。
