# NetGo 当前进度

更新：2026-11-28（Asia/Shanghai）。当前 **0.3.0-dev / API v2 / schema 8**。本轮基线 `f2f1e60`；详细行为、验证与清理结果见 [当前重构记录](REFACTOR_CURRENT.zh-CN.md)。

- Go 与 Windows 原生客户端增加刷新恢复屏障及短时重试，避免轮换响应丢失后使用旧 token 导致远控提前退出。共享远控识别恢复中的暂时错误；取消、撤权和 watchdog 到期仍终止。
- 账号异常面板复用慢查询，翻页/操作/卸载才使旧请求失效；读取与操作错误分开。人工操作条件由服务端 `can_manage` 决定，管理审计补充操作者。
- 管理页面、摘要、审计、网络设置和任务状态由 Go DTO 生成 TypeScript。API 认证、响应、管理读写与客户端签名传输职责拆分，保留现有 Vue 设计。
- 管理及远控读取贯通取消上下文；远控授权变更只载入相关实体。网络策略版本不受名称、编辑版本及重试元数据干扰。
- 原生清单移除未消费的 grants/sessions；文件与剪贴板工作线程懒启动并按事件/截止时间唤醒；Windows 解码路径借用 NV12 平面，减少一次整帧复制并复用色度计算。
- 已删除失效的全表远控策略入口和辅助代码；不维护旧开发 API/schema 兼容。必要的 VPN 全局事务栅栏与平台环境适配保留。

必要验证已完成：相关 9 个 Go 包 race、修改涉及的 vet、前端 11 项及生产构建、共享 C++ 文件/异步/控制分类、Windows 像素与合成编解码、修改文件严格编译及 Linux 服务端交叉编译。没有运行完整测试矩阵。

本机 Node 24.18.0 低于项目要求 26.13.1；定向 C++ 测试使用系统 OpenSSL 3.6.3，不作为锁定依赖发行构建证据。未做 Apple/Linux 图形端构建、移动真机或跨设备长期性能验收。Windows 查看端仍使用 CPU 颜色转换和 GDI 展示；本轮未改为 GPU 呈现。
