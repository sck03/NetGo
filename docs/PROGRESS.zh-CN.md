# 当前进度

更新：2026-11-27（Asia/Shanghai）。当前为 **0.3.0-dev / API v2 / schema 4**，客户端、控制服务及 NetBird 补丁须一起构建，不提供旧 API、旧 schema 或旧候选配置兼容。

当前实现与本轮必要验证以 [重构记录](REFACTOR_2026-11-27.zh-CN.md) 为准。以前的 evidence 和带日期报告仅证明各自历史提交，不能作为当前代码已经完成全部验收的依据。

## 本轮结果

- 修复 Windows 空资源路由选择，支持仅远控及未选互联网模式；重复 CIDR 只选择一次。
- 修复普通客户端选择不同中继时无法会合的问题。网关身份来自受信站点配置，Relay 地址仍必须由 Management 发布。
- nftables 在检查/清理后重新计算租约剩余时间；保留事务、撤权保护批次及 conntrack 清理顺序。
- Web 管理页并发普通请求和独占凭据轮换分离，不重放创建/删除等操作。
- 原生远控列表按 50 台分页，各端同步读取契约；Windows IPC 响应上限与 HTTP/共享远控一致，并返回明确超限错误。
- Windows 探测与 HTTP 等待可取消；渲染只保存最新已解码帧，绘制期间不持工作线程锁。偏好设置的解析/持久化独立于窗口代码。
- 控制请求临时失败仅在原有 6 秒 watchdog 内重试，丢失续租响应后重新读取序列；显示采集短暂丢失最多尝试恢复 3 秒。
- 远控和运行状态 DTO 从 Go 生成 TypeScript，漂移检查纳入现有契约测试。

## 验证范围

本轮完成涉及模块的 Go race/vet、前端定向测试与生产构建、Windows 原生编译、相关 CTest 与 TLS 回环检查、上游补丁定向测试和源码一致性核验。Linux amd64 命令入口完成交叉编译。

本轮未执行完整测试、真实 Linux nftables/conntrack 内核验收、跨设备全链路远控及长时间压力测试。Windows 显示恢复仍需实际显示器/驱动验证；其他设备只同步接口，不确认设备验收完成。不能把上述检查等同于“全部功能完善、没有 BUG”。

## 保留的产品边界

Windows 登录前/UAC 安全桌面、完整多显示器和旋转显示、自适应码率尚未支持。服务端续租仍扫描活动网关成员，开销随租约数量增长；本轮保持可验证的事务隔离和失败关闭顺序，不宣称固定开销或已经完成容量验收。
