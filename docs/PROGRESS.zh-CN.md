# 当前进度

更新：2026-11-27（Asia/Shanghai）。当前为 **0.3.0-dev / API v2 / schema 4**。客户端、服务端和 NetBird 补丁同步构建；不保留旧 API、旧数据库或旧 Windows 无人值守标记的兼容逻辑。

本轮以 `ffb34ff` 为基线，修复结果、必要验证及清理记录见 [稳定性重构](REFACTOR_STABILITY_2026-11-27.zh-CN.md)。历史报告只证明各自提交，不能作为当前代码完成全部验收的依据。

## 已实现

- 引擎锁等待与异步管道读写共用 25 秒期限；Agent 消失后在后台恢复，清理失败仍显式报错。普通手动配置使用引导版本 0，首次连接同步服务端正式配置。
- 远控窗口和子进程按站点隔离；查看端文件读写、flush 与超时处理移出媒体循环，文件命令超时不再终止媒体。解码复用 NV12 与最多三个 BGRA 画面缓冲，软件路径支持分辨率缩小时的固定画布缩放。
- VPN 获取/撤销/清理及远控主机/授权变更不再加载关闭历史；保留完整所有权修改和签发防重放事务。网页生产构建、DTO 契约及相关前端回归通过。
- Windows 引擎只接收去重 CIDR 投影，RPC 两端统一为 2 MiB 有界请求；不再随路由发送名称和端口。
- 开机启动、自动连接和无人值守使用统一设置存储，跨进程修改受锁保护并通知界面。关闭依赖选项会关闭无人值守恢复；删除凭据或更换信任会清除相关自动连接设置。
- 租约到期/临时网络失败可按用户设置重新认证，以新 generation 和新租约恢复。主动断开、授权拒绝和会话冲突不会自动抢占或重试。
- 主窗口拥有远控子进程生命周期；退出发起共享关闭，进程作业对象负责最终回收。
- Windows DNS 多地址错峰连接，HTTP 增量分帧，保留 TLS 身份校验与取消。
- 远控补充独立鼠标光标合成；音频故障可降级；有界文件工作队列隔离媒体循环，发布文件及发送结果前复核权限。GPU 编码使用最多 8 个样本的资源池。
- 未变化的网关授权使用单租约增量续期，避免每次扫描全部成员、序列化完整策略及刷新全部集合。SQL 提交、撤权、网关失败关闭仍在同一保护边界；策略变化、过期、helper 重启和定期修复走完整流程。

## 验证边界

仅执行与改动相关的定向测试、编译和协议回环检查，详见本轮记录。没有执行全仓库或全平台完整测试。Linux 命令入口交叉编译不等同于 nftables/conntrack 内核验收；光标合成、GPU 样本池、休眠和跨设备远控仍需 Windows 与真实 Linux 服务端联调。

登录前/UAC 安全桌面、完整多显示器与旋转、自适应码率仍是后续能力。查看端仍有 CPU 颜色转换/GDI 呈现路径。网关的宿主规则检查和完整修复仍有系统 IO 成本，不能把存储基准当作整体容量承诺。其他平台仅同步共享组件，不确认设备验收完成。
