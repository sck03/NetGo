本轮基线：`92cf74a`。按审查结论实施必要修复和优化，保持 **0.3.0-dev / API v2 / schema 4**，服务端与客户端成套更新，不增加旧接口、旧 DTO 或旧数据库兼容层。本文只记录本轮实际执行范围；此前 [审查落实记录](REFACTOR_DELIVERY_2026-11-26.zh-CN.md) 中的全矩阵、race、微基准和清理数字均属于历史提交。

## 改动与模块边界

| 范围 | 本轮结果 |
| --- | --- |
| Go 连接流程 | `internal/client/connection.go` 负责连接和恢复；`routes.go` 管理路由选择及冲突检查。每次路由调用最多 15 秒，认证刷新后的引擎登录/启动/路由共用 20 秒，更短父期限和取消优先。 |
| Windows 传输 | 同一候选的探测、普通/VPN、远控请求各用一条持久 TLS 连接；锁等待纳入请求截止时间。保持证书验证、凭据轮换同步和写请求不重放。 |
| Apple / Android 生命周期 | iOS 的 `TunnelRuntime` 独立持有和恢复系统隧道管理器，订阅状态，处理加载期间停止；Android 依据界面可见/连接状态暂停轮询并撤下终止后的通知，初始化查询失败可以重试。Apple 保存上次连接站点，旧快照不会覆盖用户新选择。 |
| 账号 | 登录名不可改、显示名可编辑，阻止改登录名破坏本地身份索引。显示名持久化于 NetGo 账号字段；更新不新增上游资料编辑能力。 |
| 管理页 | 主机和账号选择都使用服务端搜索/50 项分页；账号跨页保留选中项及名称；历史页独立返回标签。复用原有卡片、表单、分页及反馈样式，无新增 UI 依赖。 |
| 定向存储读取 | 注册只读账号及其设备；刷新只读指定凭据及绑定的活动远控；远控扫描只读相关依赖；读入范围缩小但原有事务、写锁、配额、授权与撤权规则不变。 |
| 共享远控与原生适配 | 查看器在会话激活后直接续租，去掉每次续租前的重复 GET，仍验证递增序号和权限；Android/Apple 增加仅查看、音频选择；Linux X11 累计小幅滚动，并在释放输入时清空。 |

共享 ABI、服务端领域、数据库选择逻辑和平台 UI 保持独立。未增加第二套身份或权限系统，也未引入沉重依赖。具体响应、分页和生命周期见 [统一契约](INTEGRATION_CONTRACT.zh-CN.md)。

删除旧 `admin/state?section=remote` 全量账号读取、写入后从不使用的移动 DNS 缓存字段、过时的多 EXE 构建清理分支及请求分类。SDK 要求的 DNS 回调仍保留，实际 DNS 行为不变。诊断导出、策略核对与各平台适配有现有调用方，继续保留；锁定上游不支持假定的用户详情 GET，因此没有用不存在的接口或陈旧缓存替换上游账号状态检查。
