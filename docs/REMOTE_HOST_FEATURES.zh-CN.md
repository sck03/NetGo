# 远程桌面主机与传输功能（2026-11-26）

本轮在现有站点认证、VPN 和六项权限门禁上增加原生主机与传输能力。LAN 服务端、管理页面和客户端必须使用同一轮版本；不保留旧的主机登记格式或共享客户端 ABI。构建与协议测试记录见本文件末尾和本轮验证报告。编译成功不能替代真实 GPU、桌面权限、睡眠恢复及跨设备验收。

## 已实现范围

| 能力 | Windows | macOS | Linux | Android / iOS |
| --- | --- | --- | --- | --- |
| 被控主机 | DXGI 桌面采集、SendInput | ScreenCaptureKit、CGEvent | X11 + XTest；Wayland RemoteDesktop/ScreenCast portal + PipeWire | 控制端；不提供系统级被控 |
| 硬件编码 | D3D11 BGRA → GPU NV12 → Media Foundation 硬件 H.264；初始化不可用时显式软件回退 | NV12 CVPixelBuffer → VideoToolbox 硬件 H.264；无硬件编码器时报告失败 | 尝试 VA、NVIDIA H.264，最后 x264；由系统插件和驱动决定 | 使用原有平台解码器 |
| 无人值守 | 本地启用、Credential Manager、Windows 登录启动与 VPN/共享恢复 | 本地启用、Keychain、ServiceManagement 登录启动与 VPN/共享恢复 | 本地启用、受保护凭据文件、XDG autostart 与 VPN/共享恢复 | 不作为无人值守主机 |
| 文本剪贴板 | 主机与控制端 | 主机与控制端 | 主机与控制端 | 控制端 |
| 文件上传/下载 | 主机与控制端 | 主机与控制端 | 主机与控制端 | 控制端；系统文件选择/导出 |
| 音频 | WASAPI，探测成功才登记 | 暂不登记 | 暂不登记 | 仍按主机实际能力协商 |

Windows/macOS 硬件路径不把原始画面回读到 CPU。Windows 软件回退有 CPU 回读；Linux 的当前 GStreamer 管线可能上传 CPU 内存，不宣称跨 PipeWire/VA/NVIDIA 全链路零复制。当前按宽高比限制至 1280×720、20 fps；没有已完成的动态码率或 4K 性能承诺。背压限制在途帧、压缩队列与传输消息；禁止静默丢弃已编码参考帧。

## 使用步骤

1. 两端导入同一站点配置并连接 VPN，在管理页面给控制账号授予目标主机的观看、输入、剪贴板、上传、下载等所需权限。授权项只显示该主机实际登记的能力。
2. Windows 打开远程桌面窗口，选择允许本机远控。需要登录恢复时，先在主界面记住密码并成功连接，再勾选无人值守并开启共享。最小化可保持共享；停止或关闭远控窗口撤销该共享自动启动设置。
3. macOS/Linux 在连接前勾选保存凭据并登录恢复的无人值守选项，成功登录后自动开启共享。已经连接但尚未保存凭据时，需重新登录一次。取消选项会停止共享、清除保存的登录秘密并移除该平台登录启动项。明确断开或停止会暂停本次进程的自动恢复。
4. macOS 共享需要屏幕录制授权；仅查看不要求辅助功能。已获得辅助功能权限才登记键鼠能力，之后新增授权需重新开启共享。打开媒体时仍重新检查实际权限。登录项目可能需要在系统设置批准，且受应用签名/安装位置限制。Linux Wayland 先显示桌面系统授权界面，然后才登记为可连接主机；门户允许持久授权时保存一次性轮换的恢复令牌，拒绝或撤销后不绕过系统提示。
5. 控制端连接后，可显式发送/获取文本剪贴板，选择本地文件上传，刷新交换目录并选择下载。Android 从系统文档选择器读取文件，下载后通过系统保存选择器导出；Apple 使用系统选择器与分享/保存入口。

Android/Apple 连接前可选择仅查看及是否请求音频，实际仍取主机能力与账号授权的交集。iOS 再次打开应用会接回系统中保存的隧道；Android 无连接且界面不可见时暂停状态查询，断开后撤下前台通知。Linux X11 支持累计触控板细粒度滚动。

Android/Apple 的文字框用于编辑本次要发送的草稿，点击发送后才提交，单次上限为 8192 UTF-8 字节；超限请分段。队列拒绝时保留文字，退格与回车使用独立按钮。Apple 每次下载使用独立目录，允许多次下载同名文件，完成文件可分享或删除。Windows/Linux 下载应选择新的文件名，共享核心不会覆盖已有目标。下载成功保留的是用户文件，取消/失败只清理本次临时文件。

无人值守指已登录操作系统的交互用户会话。它仍要求有效的站点账号、设备身份、VPN 租约和远控授权，不是匿名口令访问。重启后重新认证并生成新的主机传输密钥、boot 和票据；不会恢复旧租约。Windows 登录前桌面、锁屏/UAC 安全桌面控制，以及无图形会话的 Linux，不在本轮支持范围内。macOS 系统权限或 Wayland 门户策略不允许时必须由本机用户处理。

## 传输和资源边界

- 共享主机执行器位于 packages/remote-client/src/host.cpp；平台只实现采集、输入、剪贴板、同意和状态回调。设备私钥留在既有连接服务，主机传输密钥每次启动随机生成。
- 观看、输入、音频、剪贴板、上传、下载分别授权。文本剪贴板显式操作，UTF-8 上限 8192 字节，不做后台自动同步或富文本/图片同步。
- 主机文件仅位于用户数据目录下的 Exchange。单层文件名，拒绝路径穿越、分隔符、设备保留名、符号链接、重解析点、硬链接及非普通文件；不覆盖已有文件，不执行文件或命令。
- 单文件上限 1 GiB，交换目录接收预算 256 文件 / 2 GiB，32 KiB 分块。一个控制会话只进行一项文件传输，最多排队 4 项 UI 命令；最多 8 个有序分块在途，单次媒体循环最多提交 4 个分块。提交文件和取消操作等待在途响应，只有完整大小与 SHA-256 校验通过才发布文件。输入和续租先于新文件分块排入有界发送队列。
- 上传使用随机临时文件，顺序偏移和 SHA-256 完整性验证后发布。下载也先写临时文件。取消、错误、断线、撤权都会关闭文件并清理未发布文件；已经成功完成的文件保留。
- 同一主机仅一个活动会话；命令限速和截止时间、控制面 watchdog、票据单调过期与取消门禁共同限制资源。文件流量和视频共用 TLS 通道，尚未提供独立 QoS 或自适应带宽分配。
- Linux 凭据复用既有 vault，文件 0600、目录 0700，未增加 OS 磁盘加密；macOS 使用 Keychain、Windows 使用 Credential Manager。设置文件只含站点和选项，恢复令牌不包含站点密码。信任根或控制身份变化要求重新登录。

## 验证与维护

本轮新增 remote-host 集成测试，在回环真实 TLS 上运行共享主机与控制端，验证持钥证明、本机拒绝、无人值守授权、剪贴板和文件往返，无需读取真实桌面。remote-files 覆盖目录边界、偏移/令牌、哈希、覆盖拒绝、取消与传输中降权。Go 覆盖平台能力、主机传输密钥轮换、保存凭据的当前代次、显式取消及信任绑定。

下一步真实设备验收须记录 GPU/驱动、实际编码后端、CPU/GPU/内存、帧延迟、不同 RTT 下传输速度、睡眠/网络变化和权限撤销。至少覆盖 Intel/AMD/NVIDIA Windows，Apple Silicon macOS，Linux X11 与 GNOME/KDE Wayland，以及 Android/iOS 文件选择器切换生命周期。当前测试没有代替这些项目。开发机 AMD RX 580 2048SP 已通过合成画面的 GPU NV12 → 硬件 H.264 → 解码 40/40 帧验证，未读取真实桌面；命令与证据见 [GPU 记录](https://github.com/sck03/NetGo/blob/92969551d3989395bcf2556702649ed9dc9c8e3b/docs/evidence/2026-11-26-remote-host/gpu-probe.txt)。

实现与参考来源见 [设计决策 0006](adr/0006-remote-host-and-exchange.md)。当前验证结果见 [本轮交付记录](REMOTE_FEATURES_2026-11-26.zh-CN.md)。

## 2026-11-27 更新

原生主机列表使用每页 50 台的 cursor 接口，Windows、Linux 与移动/Apple 调用同步读取。跨平台适配属于代码一致性更新，不代表新增设备已实测。

Windows 展示任务合并，最多保留最新已解码画面，不丢弃 H.264 参考包。源分辨率变化时重建编码器并维持本会话的协商尺寸；采集失效最多尝试恢复 3 秒。恢复期间释放按键并忽略新输入，授权仍由共享会话门禁控制。

共享控制监视器区分暂时传输失败与明确授权拒绝，重试不延长原有 6 秒期限。已过期/撤销的会话必须重新申请。当前验证见 [重构记录](REFACTOR_2026-11-27.zh-CN.md)。
