# Windows 与服务端稳定性重构

日期：2026-11-27（Asia/Shanghai）。基线 `1e35cff`。维持 0.3.0-dev / API v2 / schema 4，各组件同步构建，不提供旧开发版本兼容。此次实施针对代码审查中的缺陷和成本来源；产品长期目标仍以实现清单中的待验收项为准。

## 修复与架构边界

| 范围 | 实现与行为 |
| --- | --- |
| 路由容量 | Windows 将资源投影为去重 CIDR，移除名称、端口、协议等引擎不用的字段。C++ 与上游 RPC 统一 2 MiB 请求限制，并区分容量错误与管道写入错误；网关继续限制 1 MiB / 1024 租约。 |
| Windows 设置 | `UiPreferences::update` 统一读改写、类型约束、跨进程互斥和通知；窗口只修改自己负责的字段。无人值守依赖保存凭据、开机启动及自动连接，关闭依赖或删除凭据会撤销恢复设置。相同设置不重复写盘。旧独立标记逻辑删除。 |
| 连接恢复 | 临时网络错误或租约到期后，按用户设置以 1–30 秒退避重新认证，读取当前受信配置，递增 generation 并获得新租约。授权拒绝、会话冲突、清理失败和主动取消均停止，不自动替换其他设备会话。 |
| 进程所有权 | `RemoteProcess` 负责启动、显示、停止和 Job Object 回收，窗口不再自行启动无句柄的远控进程。退出程序保留下次登录偏好，主动停止共享会关闭无人值守。 |
| 控制传输 | DNS 多地址连接错峰 200 ms，最多 8 个同时尝试，单连接尝试 2 秒并服从总截止时间。HTTP 增量处理头、固定长度、chunk/trailer，完整后才解码正文；格式错误立即失败，不再用反复抛异常表示“未收完”。 |
| 音视频 | 单独的 `CursorSurface` 复用 GDI 兼容纹理处理独立系统光标；音频初始化/播放失败降级为画面连接。GPU 编码使用 Media Foundation 样本池，最多 8 个样本，避免复用仍被编码器持有的纹理。 |
| 文件与媒体隔离 | `CommandWorker` 使用单工作线程、最多 8 个未完成命令；媒体和授权循环继续运行。排队结果发送前重新检查对应能力，文件 flush 后发布前复核授权；退出取消排队工作并 join。非法命令字段在异常边界内处理，上传分块读取错误只取消文件传输。C ABI 注明回调线程和销毁顺序。 |
| 服务端续租 | Store 保留 SQL 写事务，Manager 只对已应用且身份/资源未变的租约申请增量续期；容量通过序列化增量核对。helper 的 `/renew` 只接收一个租约，未知状态返回完整应用请求。NFT 在一个原子批次删除并重加目标成员；过期、策略变化、helper 重启、批次失败或定期修复走完整保护流程。撤权、conntrack 和失败关闭边界保留。 |

管理网页已有的账号、资源、远控权限、停止、审计、诊断及策略重试入口继续使用现有公开接口；此次没有新增网页业务接口或特权运维入口。Go → TypeScript 漂移检查继续约束前后端 DTO。Windows 控件保持现有任务导向布局，只调整设置语义和错误提示。

## 必要验证

- Go：`store/session/gateway/privileged/contracts` 定向 race 测试；相关 vet；Linux amd64 的相关 vet 与本仓库 `cmd/...` 交叉编译。
- Windows：原生程序编译，native-core、native-ipc、native-profile-contract、remote-video-codec、remote-host、remote-files、remote-client 共 7 项定向 CTest。覆盖资源投影、大于旧 64 KiB 的合法资源组合、设置依赖、HTTP 任意分段、文件队列和发布时撤权。
- TLS 回环：证书身份、签名、多入口、服务端时间偏移、取消、独立清理和控制请求隔离。
- 上游 RPC：请求上限和精简 DTO 同步修改，补丁格式检查及两项定向请求边界测试通过。
- 最终异常边界补充后，Windows 再编译及 remote-host / remote-files 定向回归通过；非法 action 后工作线程仍可处理下一条合法命令。
- 清理脚本保留路径/链接/活动进程保护，并新增 Git 已跟踪文件保护；默认预览，显式 `-Apply` 执行。

最终原生 `NetGo.exe` 为 7,395,328 字节（约 7.05 MiB）；这是本机编译的产品入口，不包含 NetBird、Wintun 或安装包。没有测量本轮真实媒体的 CPU、内存和端到端延迟，不能据此给出整体性能提升百分比。

没有运行全仓库完整测试、全平台构建、真实 Linux nftables/conntrack 内核验收或 72 小时压力测试。上游完整发行包和跨设备远控不在本轮验证范围。

## 存储路径基准

Windows amd64、Go 1.27.4、内存 SQLite，单次 100 ms 基准，固定当前身份，只延长其租约，增量 gate 回调不执行真实 IO：

| 活跃租约数 | 时间 / 次 | 累计分配 / 次 | 分配次数 |
| --- | --- | --- | --- |
| 16 | 0.182 ms | 11,313 B | 164 |
| 128 | 0.183 ms | 11,074 B | 164 |
| 1024 | 0.180 ms | 11,075 B | 164 |

该结果只验证正常增量路径已移除全成员解码成本，不是服务端吞吐量。宿主 nftables 规则检查仍有外部 IO，策略变化和周期修复仍进行全量处理；数据库写入和权限更新继续串行化。

## 清理与剩余边界

清理对象为可重建的工具链下载、OpenSSL 构建源码/依赖、原生与 Linux 测试产物、上游验证副本、node_modules、旧测试运行目录及日志。项目扫描未发现业务数据库；缓存中的第三方测试数据库随副本清理。保留源码、当前网页 embed、固定版本清单、构建脚本和有效历史报告，不清理系统安装或仓库之外的共享缓存。

本轮清理预览中的 14 个目标共回收 1,180,687,831 字节（约 1.10 GiB），工作区文件逻辑体积从约 1.11 GiB 降至约 5.8 MiB（含 Git 历史，提交前测量），减少约 99.5%。复查清理清单的可回收文件为 0 字节。旧测试引擎经进程镜像路径核对后已停止；清理脚本补充普通进程查询漏报时的镜像查询，以及部分删除后的重试处理。一个已无文件的 OpenSSL 目录树因自动审批策略拒绝删除而保留；空目录不计入上述文件字节数。

分支检查：本地与 origin 均只包含 main，无需合并或删除其他分支。使用正常提交和推送，不改写 Git 历史。

复用命令：`pwsh -NoProfile -File scripts/clean-workspace.ps1 -IncludeToolchains -IncludeTestData` 先预览，增加 `-Apply` 删除。清理后再次构建会按固定版本重新下载依赖。

仍需真实设备确认：Windows 休眠/换网、鼠标形状、显示模式切换、GPU 驱动、音频设备变化、跨设备文件与媒体并行，以及 Linux 增量集合更新和撤权。登录前/UAC 桌面、多屏/旋转、自适应码率尚未实现；查看端保留 CPU 颜色转换/GDI 呈现。其他平台只同步共享组件，不确认设备验收完成。
